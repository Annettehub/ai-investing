## 一句话结论

这组资料的入库价值不在于“数学是否已被 AI 攻克”，而在于提示一个 G3/L4 新问题：当模型开始处理可验证、可形式化、可并行搜索的研究任务时，推理需求可能从聊天/API 扩展到“科学发现工作流”，但其经济价值和真实性仍需独立验证。

## 核心观点

1. **数学是观察 AI 能力前沿的高质量窗口**
   - 数学和编程任务具有可验证、可反复训练、可并行搜索的结构。
   - Grant Sanderson 认为，IMO 金牌不等于 AGI，真正重要的是模型能否提出有价值的猜想、定义和概念框架。

2. **AI 科学发现的关键可能是“跨领域连接”**
   - 模型如果能同时掌握多个数学领域，可能发现人类不易察觉的连接。
   - 重大突破可能来自“造山”（新概念框架）和“闪电”（跨领域连接）。

3. **Astra 相关资料需要保留核验边界**
   - Didier 资料称 OpenAI/Astra 一次性提交多项数学成果，并附推理过程和 Lean 形式化证书。
   - 这些成果若经独立审查成立，可能代表模型从解决给定难题进入批量生产未知知识。
   - 但当前不宜把它直接表述为数学已被 AI 攻克，正确性、原创性和形式化边界仍需专家验证。

4. **研究成本可能出现数量级下降**
   - Didier 资料称十项解法对应的推理 token 按 Sol API 价格约 2000 美元。
   - 该数字不含训练、失败任务、筛选、人类整理和固定成本，不能机械外推。
   - 但方向上提示：科学发现的边际成本可能从专家多年工作，下降到模型集群运行若干小时或若干天。

5. **Symborg/认知组织提示 Agent 工作流的新形态**
   - 资料把 Agent 与人的目的、组织、协作区分开。
   - 对 G3 的意义是：未来推理需求可能不只来自单次问答，而来自多人/多 Agent/多工具的研究组织过程。

## 需要跟踪的指标

1. Astra/OpenAI 数学成果是否通过独立同行审查。
2. 形式化证明、Lean 证书和自然语言论文之间是否存在语义偏差。
3. 科学研究 Agent 是否从演示进入真实科研工作流。
4. 推理 token 成本是否足以支持高频研究搜索，而不是一次性展示。
5. AI 生成新知识是否形成商业化入口、平台或科研服务收入。
