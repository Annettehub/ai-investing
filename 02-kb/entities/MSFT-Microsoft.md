## 当前核心判断

Microsoft 的 AI 价值不能只看 Copilot seat 数和 CAPEX headline。更重要的是：Azure/OpenAI token 用量是否转化为收入，Copilot 是否从试用 seat 转为真实 revenue，AI 云是否守住毛利和 OPM，以及企业客户是否通过 workflow/agent 获得 ROI。

## 2026-08-08 更新 #1

- **触发**: FAU-2030 微软云专家访谈入库。
- **核心观点**:
  - MaaS 收入中约 70% 来自 OAI GPT API，Claude 占比去年不到 10%。
  - 智能云 OPM 受 LTA 锁价、传统云 capacity 释放和租赁会计变化影响。
  - Copilot 付费 seat 不等于实际收入，关键是实际 revenue、活跃使用、续约和企业 workflow ROI。
  - 世界 500 强中 80%-90% 客户基本完成 POC，5 万席以上大客户同比增长 6-7 倍。
  - Copilot 可能从标准版向 $99 打包版、高阶版和 token 化收费迁移。
  - Nebius 是 Microsoft AI 云生态中的双向资源节点，但其租用 Azure 规模较小。
- **影响维度**: G1 / R1 / R2 / S3。

- **置信度**: 中；专家口径，需微软财报、IR 和客户案例验证。
