Anthropic与RUM Group的137亿美元算力交易：商业刚需，还是向特朗普阵营示好？



交易背景

2026年8月23日，RUM Group（纳斯达克：RUM，原Rumble）在SEC文件中披露：与一家未具名的美国云客户签订约137亿美元、为期六年的GPU服务合同，算力来自佐治亚州Maysville尚在建设的数据中心。客户还将获得最多约5081万股RUM Class A股票的认股权证，行权价仅1美分，随采购进度分批兑现。第三期订单还要看客户是否认可交付时间表。
9月14日，《The Information》的报道经多家媒体转述：这家未具名客户就是Anthropic。RUM官方文件至今仍写"unaffiliated U.S.-based third-party cloud customer"，双方都未发联合声明。在公开信息里，这仍是一则有来源、但尚未被公司点名确认的报道。
即便如此，交易本身已经足够刺眼：一边是与白宫多次公开对峙的Claude厂商，一边是托管Truth Social、被媒体称作"Trump-linked"的视频平台转算力公司。问题随之而来——这是Anthropic在买算力，还是在买政治保险？


一、这笔交易到底买了什么



按RUM披露

1. 标的：Maysville园区的GPU及配套服务，该园区原属Northern Data，规划约180MW；
2. 金额与结构：总订单价值约137亿美元，分三期；第三期取决于客户对交付日期的认可；
3. 股权彩蛋：最多约5081万股、行权价0.01美元的权证，随采购兑现。按近期股价粗算，这是一张潜在价值数亿美元的几乎免费期权；
4. 风险：RUM自己写明，目前没有完成履约所需融资，合同也不以融资为生效条件。建厂、买卡、接电、许可全部要自己扛；融不到钱也要履约，否则可能面对客户索赔；
5. 对Anthropic而言，这只是过去一年算力采购里的一单。公开统计显示，它在约11个月内签下约5170亿美元、合计约14.8GW的算力协议，对手包括AWS、Google/Broadcom、AMD、SpaceX/AI的Colossus、Nscale（约450亿）、Lambda（约350亿）、Riot、CoreWeave、Fluidstack等。Maysville这一单规模不小，但远不是最大的一笔；
RUM也坦言，园区还在建，2027年前才能真正贡献产能。合同签的是未来产能，不是现货GPU。


二、RUM Group是谁



从视频网站到算力公司的转型

RUM Group的前身是Rumble：2013年由Chris Pavlovski创办的视频网站，定位是对抗YouTube审查的"freedom-first"平台。2022年借SPAC上市，代码RUM。2026年6月完成对德国AI云公司Northern Data的收购（约7.67亿美元全股票），改名为RUM Group，拆成两块：
1. Rumble：视频、直播、广告、加密钱包；为特朗普的Truth Social提供托管与云服务；
2. Quake AI：Northern Data的约2.2万张Nvidia H100/H200，加上欧美多个数据中心，以及美国Maysville这块待开发电力。公司对外目标是2027年前后把未货币化电力做成数十亿美元量级的年收入。
视频业务体量仍小，长期亏损。真正改变估值叙事的，是"视频公司突然变成有电、有卡、有地的neocloud"。


三、股东结构：钱在Tether，票在Pavlovski



近年股权大致是这样

1. 经济大股东：USDT母公司Tether（Tether Global / Tether Holdings，Giancarlo Devasini），约1.42亿股Class A + 大量几乎零成本Pre-Funded Warrant，受益所有权约50%上下；投票权被压在约9.9%
2. 实际控制人：Chris Pavlovski（创始人、董事长、CEO），通过高票Class D等安排掌握约83%投票权
3. 其他内部人：Ryan Milnes等董事/早期股东，千万股量级
4. 机构：Cantor Fitzgerald（Tether关联公司）、Cooper Creek、BlackRock、Vanguard等，合计约20%流通盘
Tether 2024年底向Rumble投了7.75亿美元，后来又承诺采购GPU、投放广告，并在Northern Data交易中既是卖方相关方、又是合并后的锚点客户。RUM的资本故事，很大一块是稳定币巨头在搭一条"去中心化、反审查"的算力与内容栈。


四、和特朗普、JD Vance是什么关系



必须把"关联"和"所有权"分开

和特朗普的关系：

和JD Vance的关系：

2. Vance离开Narya后，仍持有该基金部分权益；早期个人披露里也有对Rumble的直接投资（约10-25万美元档）；

一句话：RUM处在特朗普媒体生态和MAGA科技圈里，钱主要来自Tether，控制权在Pavlovski，Vance是早期财务关系，不是现在的操盘手。


五、Anthropic为什么会找到这家公司



核心原因是算力饥渴，不是政治站队

Anthropic的处境很简单，Claude的需求把算力吃干了。公司已秘密递交IPO材料，估值传闻从数千亿美元到更高级不等；收入年化一度被搜到数百亿美元级别。芯片、电力、机柜全是瓶颈。谁能在2027-2028年交出可用兆瓦，谁就在谈判桌上。
RUM/Northern Data的卖点不是品牌，而是：
1. 美国东南部一块已有规划的电力土地（Maysville）；
2. 欧洲已部署的GPU集群可作过渡；
3. 愿意给几乎免费的股权权证，这对缺资本开支的买方是融资工具，对卖方则是锁定产能的甜头；
4. 不走AWS/Google/Azure的队列。Anthropic过去一年刻意把供给多元化，连xAI的Colossus都包过。
从采购视角，RUM是"有地、有电有规划、报价激进、肯送股权"的新云商，和Lambda、Nscale、Riot同类。政治标签不是合同里的唯一变量。


六、这算不算向"特朗普集团"示好？



支持"示好/对冲"的理由

过去一年，Anthropic与特朗普政府的关系几乎是硅谷最差的一档：
1. 拒绝五角大楼合同里关于国内监控、自动化攻击武器等条款，被国防部标成供应链风险；
2. 最强模型一度被限制出口、对外国用户关闭；
3. 官员公开骂Dario Amodei："ideological lunatic""leftwing nut jobs"；Amodei也曾有过对特朗普极重的私人评价；
4. 白宫一度更愿意联合创始人Tom Brown谈，而不是跟Amodei谈。
与此同时，OpenAI、Meta走的是另一条路：捐款、捐款跟典、接受军方条款。Anthropic雇了共和党顾问（如Chris Liddell、Roy Blunt），但始终没有完成那套"标准投名状"。
2026年9月初，商务部长Lutnick公开说"We trust Anthropic"，关系刚开始回暖。此时把上百亿美元算力订单（外加廉价股权）放进一家托管Truth Social、被市场视为MAGA科技股的公司，客观上会给白宫、给MAGA资本圈一个信号：Claude不是只跟"蓝州云"做生意。
1. 美分权证尤其像政治解读的燃料：客户不仅租卡，还可能成为RUM的潜在股东。RUM涨，客户账上就有纸面收益；
2. RUM要融资建厂，也等于让这家AI巨头背书它。



反对"就是投名状"的理由

1. 特朗普并不控股RUM。钱流向Pavlovski、Tether和公众股东，不是DJT或特朗普个人账户。说"向特朗普集团示好"时，必须说明：示好的是生态与叙事，不是把支票开给总统本人；
2. Anthropic几乎跟所有能交货的人签单，包括马斯克体系的Colossus。如果包下xAI算力不算"投靠马斯克"，单签RUM也自动等于投靠特朗普；
3. 合同风险极高。园区未建成、卖方自称没钱、第三期可黄。这更像饥不择食锁产能，而不是精心设计的政治献金。真正的献金或超级PAC捐款，路径更干净、更可追踪；
4. 时间线也不完全吻合"求和剧本"。8月底签单，9月中Amodei还在发长文要求放缓前沿模型、被特朗普当场斥为"negative forces""whoever wins AI wins"。一边买MAGA云的卡，一边公开唱反调，更像公司内部"安全派CEO"和"算力/政策团队"各干各的，而不是一张精密的投名状。



更可能的真实结构

把三件事叠在一起看，会清楚很多：
1. 采购层：2027年美国电力和Blackwell/Rubin级产能极度稀缺，谁有地谁就有合同；
2. 资本层：RUM需要一份"名头够响"的锚点客户去借钱、买卡、说服电网；Anthropic的名字比Together AI那种早期小单值钱得多；
3. 政策层：Anthropic需要降低"反特朗普硅谷公司"的标签成本，联邦合同、出口许可、数据中心地方反对，全都沾政治。把一部分capex洒到红州佐治亚、洒到托管Truth Social的供应商，成本相对可控，信号却很响。
所以更公允的表述是：这首先是一笔锁定未来产能的商业合同；在当前华盛顿气候下，它同时具备向特朗普生态释放善意的副作用。把副作用当成唯一动机，会夸大；完全否认副作用，也不诚实。

结论



核心判断

Anthropic和RUM Group的137亿合同，核心是2026-2027年美国AI算力短缺下的产能预订，附带一张几乎白送的股权期权。RUM是Tether出钱、Pavlovski掌权、业务上绑定Truth Social的MAGA科技股，Vance只是早期投资人。说Anthropic"变相向特朗普集团示好"，政治溢出是真实的，所有权链路却不是；更像一家即将上市、又刚和白宫吵完的公司，在买卡的同时，顺便使一点红色美国的入场券。
