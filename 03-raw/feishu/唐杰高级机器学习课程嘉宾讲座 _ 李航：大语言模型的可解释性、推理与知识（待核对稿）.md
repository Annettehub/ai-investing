豆包要点总结
1. LLM 不完全是黑箱：特征叠加假说认为一层网络能表示远多于神经元数量的特征；SAE（稀疏自编码器）抽取每层词典特征，CLT（跨层 transcoder）追踪特征演化与回路，可构建归因图
2. 功能词元记忆机制（字节跳动工作）：the、逗号、换行等 function token 在记忆巩固、检索与数据格式中起关键作用，功能词元之后的内容预测损失更高、激活特征更多
3. Anthropic 的发现：写诗会先激活句末押韵词再组织内容；加法计算走量级估算与精算并行的路径；思维链自述与内部计算未必一致；幻觉源于"熟悉概念抑制拒答"；越狱是安全拒绝与语言连贯性两种机制竞争
4. 推理=语句空间中的路径搜索：预训练做极大似然估计，输出"最有可能"的下文；后训练强化学习寻找"最合理"的答案；next-token prediction 等价于序列概率建模与无损压缩编码
5. 知识表示：自注意力是 KV 软检索、负责组合性（composition）；FFN 是特征检测器、记忆知识；残差连接组合不同深度路径。预训练学到 pattern、后训练引导能力，数据闭环与规模仍是未来核心

LLM 的工作机理与可解释性
我们现在天天在用 LLM，更多时候用的是 LLM agent。它展现出的能力，还有一个重要概念叫“人格”，最近 Anthropic 讲得比较多。大家能看出来，每个 LLM agent 好像都有自己的个性。模型能力上，大家都在刷榜、努力提高。

特征叠加假说

特征叠加假说
大家学神经网络，往往有个直观理解：一个神经元表示某种特征。比如 CNN 做图像分类，一个神经元可能表示物体的轮廓、一部分组件。前馈神经网络也有类似理解。
“特征”在这里没有严格定义，可以是物体的边、某个概念，就是一些能够直观理解的东西。一会儿看例子，就会知道我们把哪些东西叫作特征。
现实中很难发现某个神经元恰好只表示物体的一条边。偶尔有这种情况，但更多时候，一个神经元表示很多特征，一个特征被表征出来，又涉及多个神经元。所以有了 superposition，也就是特征叠加假说。Superposition 大家可能知道，是量子力学里也用的词。
现在已经有很多证据表明，一层神经网络确实能表示很多特征。我们考虑一个简单计算：输入 x，有权重 W 和偏置 b，再过 ReLU。这可能就是 LLM 中 FFN 的一层。

有限的神经元可通过叠加表示更多特征

特征叠加假说
实际的窄表示与假想的宽稀疏表示
现实看到的是左边；假说认为，背后存在右边这样一个更宽的网络。h̄ 的特点是稀疏：很多神经元的激活值为零，只有少量非零。我们假设，这些非零神经元各自表示一个特征。一张图片来了，只激活一部分特征，不会把所有特征都激活。这些特征也不是完全独立，相互有一定依赖，或者说有一点干扰。
我打个比方。左边的实际网络有五个神经元，就像五个房间。现在有一百个特征，就像一百个人，要全部同时来住，五个房间肯定住不下。但现实不是同时来，一次最多来六七个人，大家挤一挤，五个房间就够了。
一张实际图片不可能同时出现所有特征。假设一百个特征里只有六七个出现，就可以用五个房间容纳这一百个人。右边宽网络的意思，是假想这一百个人每个人都有一个房间；现实其实只有五个房间。有人来了，房间门口的名字换一下，大家好像各有一个自己的房间，但整体还是五个房间。
这只是帮助大家直观理解：左边是现实的窄网络，右边是假想的宽网络。重要条件是，h̄ 一定稀疏，其中的特征大体上不相互干扰。六个人挤五个房间，还是会有一点干扰，就像这些方向不是完全正交。
在 n 维高维空间里，两两几乎正交的向量，数量可以达到 n 的指数级，所以有很多共享“房间”的机会。这是高维空间的几何性质提供的保证。

特征叠加假说
数据稀疏性与高维空间几何使特征叠加成为可能
为什么能学到这种情况？一方面，数据特征是稀疏的。一张照片、一个实例，不会拥有所有特征，只有部分是一，其他是零。另一方面，学习时通过 SGD、反向传播优化参数，会促使特征以这种方式挤在一起，因为这样效果好。
ReLU 也起作用。这里 b 相当于一个阈值，弱信号被过滤掉，阈值又可以自动学出来。删掉一些弱特征、保留强特征，便能进行这样的叠加。
Anthropic 做过 toy model，也就是玩具模型的模拟实验，验证了特征叠加现象。后面介绍 SAE、CLT 时会看到，这些工具的使用也提供了证据，说明它确实是现实中的现象。

SAE：特征分析

SAE：特征分析
大家可能会问，特征叠加是不是真的存在？SAE，也就是 sparse autoencoder，可以帮助我们看。刚才叠加相当于把很多特征压缩在少量神经元里，现在反过来，能不能给我一个网络，把被压缩的特征抽出来？
SAE 有开源实现，大家可以试。原理上可以对很多网络做这种事情，但模型怎样训练出来，会影响抽到的特征是否可解释。
Sparse autoencoder 有编码器和解码器，编码器是非线性结构，解码器是线性变换。与有些常见 autoencoder 不同，这里中间非常宽。

SAE：特征分析
SAE 的编码、解码与稀疏正则化
把任意一个网络中某层的神经元表示写成 x，刚才相当于 h。我输入 x，通过编码、解码，再还原 x。中间层有很多神经元。注意，这是另外一个分析工具，不是原来神经网络那一层本身。
我们把它放在 LLM 的相应位置做分析。训练好的 LLM 跑大量数据，让它生成文章，几十个 block 中，每个 block 的输出都可以截下来、记录下来，于是有大量这样的表示数据。
要分层做：一个 block 对应一个 SAE，另一个 block 再训练另一个 SAE。同一层收集到的表示都当作输入 x，要求 SAE 尽量把它还原。这些表示叫 residual stream，也就是残差流。
test.jpg


SAE：特征分析
在 Transformer 的残差流上提取稀疏特征
刚才假设 x 中叠加了很多特征，我们希望用宽的 sparse autoencoder，把这些特征抽出来。中间层的规模，一般可能是输入的十六倍到三十二倍，至少希望有相应量级的特征叠加在 x 中。
特征集合通常叫 dictionary，也就是词典。先定 dictionary size，再学习。为什么叫 sparse？因为对中间层加 L1 penalty，希望很长的向量里只有若干特征非零，其余都是零。加上约束，大量数据进来，模型就会学到：不同输入只激活其中几个特征。
原理上可以对任意一层试，但抽到的特征是不是可解释，是另一件事。现实中，确实看到能解释 LLM 内部的特征。
Anthropic 在 Sonnet 模型上做了大量实验，抽出百万量级的特征。比如“金门大桥”：不管输入用什么语言，只要讲金门大桥，甚至图片里有金门大桥，这个特征都可能被激活。
还有“谄媚”特征，关系到回答是不是老顺从用户。把相应特征置零，回答就可以变得不那么谄媚。类似特征有很多，大概有百分之五十到六十可解释。这不是一个特别严格的统计，是我这里给大家的粗略说法。
怎样解释？看哪些输入让同一特征激活，可以做聚类，也有各种工具和标签。最后发现，这个特征对应金门大桥，那个对应其他概念。

SAE：特征分析
SAE 提取的特征、跨语言概念与层次分布
LLM 一般有几十层。底层特征往往跟词法、简单语法相关；中间层是更复杂的语法和语义；顶层则更多涉及复杂语义、推理和最后输出时的表达。每层分别训练 SAE，抽出的特征不同，意义也不同。中间还有大量功能性特征，比如大小比较。
CLT：回路分析与归因图

CLT：回路分析与归因图
另一个工具是 CLT，cross-layer transcoder。按层独立抽特征很好，但层与层本来相互关联，能不能跨层看？CLT 就是做跨层分析。
这张图里的 MLP 就是 FFN。每层有个类似 SAE 的东西，使用这一层的输入，但输出不仅加到本层，还加到后续层。于是，抽出的特征不只是表示本层的概念，也反映它怎样影响后面的概念。

CLT：回路分析与归因图
归因图的节点、影响关系与剪枝
SAE 是各层独立的；CLT 不仅看每层激活了什么，还看它们之间哪些有关联、关联强度是多少。它需要更大的算力，SAE 可以一层单独跑，CLT 要把整个模型一起考虑。真正很大的模型上跑 CLT 很困难，目前现实中更多在相对小的模型上分析，要解决不少工程问题。

LLM 的记忆机制

LLM 的记忆机制
我们在字节做过一个工作，想了解 LLM 怎样记东西。先定义两个概念：function token 和 content token，功能词元和内容词元。这跟语言学有些关系。
比如 a、the，还有逗号、回车，都是功能性的 token。它们种类不多，但在整个 corpus、语料里的占比很高。中文的“的”“了”也类似。其他表示桌子、椅子等内容的，叫 content token。
我们看到，LLM 的知识记忆很大程度上围绕 function token，这跟一些人的直觉不太一样。人记忆时，可能更以 entity、实体和内容为中心，心理学有相关研究。当然，人本身的机制也还没有完全了解清楚。
LLM 中，the、换行等功能词元在记忆知识、形成回路时起重要作用。很多细节还没有完全弄清，但可以观察到这些现象。

相反，content 接 content 往往容易一些。例如“清华”出来以后，下一词很可能是“大学”。但前面是 function，表示前一单元结束，就更难。

高频功能词元与被激活特征的关联
横轴按 token 频率排序，回车可能排第一；高频的通常有回车、逗号、句号、the、a 等功能词元。可以建一个二部图，一边是 token，一边是 feature。某个 token 激活某个 feature，就连一条边。
结果能看到，function token 激活的特征非常多，它跟很多概念有关；content token 则比较具体。比如“桌子”，更可能激活桌子、椅子等相关特征。能看到很明显的分布差异。
推理时又怎样？比如输入英文：“Answer the question in Chinese: What's the capital of Russia?”要求用中文回答。我试过自己能试的那些 LLM，没有例外，基本都能按中文回答，大家也可以试。

LLM 的记忆机制
回答语言特征与国家概念在生成过程中的激活
分析中能看到，在一些 token 位置，橘色特征被激活，表示“用中文回答”。把它 disable，就不再按中文回答。不同语言，基本也能找到类似的特征，控制用哪种语言输出。
LLM 能做很多复杂事情，里面却有这种有意思的机制：用什么语言回答，可以对应到某个特征，而且可以干预。
例子里，问到 Russia，蓝色特征被激活，表示俄罗斯，然后逐个 token 生成中文答案。换成问英国首都，同一机制下，绿色特征被激活，表示英国。
还可以看到，在冒号等关键 function token 位置，重要特征会持续激活，帮助后面回答。这项工作目前更多使用 SAE 看中间层特征，没有用 CLT 把所有细节看完。如果用 CLT，可能更清楚。但功能词元的重要作用，是我们观察得比较清楚的一个结论。

Anthropic 的发现
规划、计算、翻译、思维链与安全机制的分析
比如写诗，应该是 Claude Sonnet 的结果，我有些记不清具体模型。发现生成第二句时，它会先选择句尾的押韵词，再决定内容。
我们直观上想，next-token prediction 肯定是在第二句里一个词一个词往外生成。但它事先有 planning，会先定第二句最后一个词。
例子第一句是“He saw a carrot and had to grab it.”生成第二句之前，先想到 rabbit，第二句最后一定是 rabbit，再生成“His hunger was like a starving rabbit.”

Anthropic 的发现
先激活句末押韵词，再组织诗句内容
如果干预，把 rabbit 概念改成或抹掉，模型也可以选择 habit 等另一个押韵词，凑出另外两句有意义的诗。它不只是在做眼前下一步的预测，学习时也学到了整个 sequence 应有的条件和规划。
加法的例子也有意思。课件里是 36 + 59 = 95。停在等号这里，看内部会发现两条路：一条粗略估算结果的量级、大致范围，另一条逐位、尤其对末位进行计算，最后汇合得到结果。

Anthropic 的发现
加法计算的并行路径与模型自述的差异
简单加法，现在 LLM 一般能比较准确地做。但它不是完全死记硬背，也不一定像人一样按规则算，而有自己的机制。
你问它“怎么算的”，它可能按人学加法的方式解释：先把个位相加，进一，再加十位。这说明，模型实际做的方法，和给人的解释，可能是两回事，有点“言行不一”。它自己也未必知道内部究竟怎样做，只是训练数据里见过人这样解释。
这是一个拟人的比喻：它“脑子里”算的，可能是另一种算法。人是不是也这样，我不好说。但心理学里，元认知研究确实发现，我们自以为因为某种原因这样想，真正的过程未必如此。
再看翻译，先有概念，后有不同语言。比如用中文、英文、法文问“小的反义词是什么”。模型先识别“小”的跨语言概念，再有大小比较、反义词是“大”的概念，然后选择语言输出。

Anthropic 的发现
跨语言共享概念与目标语言表达
这里的“小”“大”不依赖具体语言，挺像一种通用的思维语言，有认知科学家叫 mentalese，也就是思维的语言。LLM 里也能看到这种现象。
思维链并不一定可信。模型生成的 chain of thought，不一定就是它内部计算的过程。有时正好一致；有时实际走了另一条路，事后编一个说法；还有时受 prompt 暗示，先定一个答案，再反过来编推理步骤。
test.jpg


Anthropic 的发现
思维链自述与内部计算未必一致
不能因为思维链写成这样，就认定内部也是这样。两者有关系，但不是完全一回事。
幻觉方面，有两个机制。一种是“不知道的东西不回答”，训练时有这样的要求；另一种是对熟悉概念总想回答。比如迈克尔·乔丹，未必知道他的所有事情，但对名字很熟，一旦问到相关故事，就可能开始编。
test.jpg


Anthropic 的发现
熟悉概念可能抑制拒答，导致幻觉
就像有一种回答冲动：我对它熟，所以想抢着回答，结果出现幻觉。现在幻觉减少，依赖于训练；但从这些机制看，要完全杜绝可能仍然很难。
越狱也有类似的机制竞争。比如问模型怎样制造炸弹，它通常会拒绝。换种说法，把敏感词拆开、分散在其他词里，再诱导，它有时又会回答。这就是本来不应该回答的危险内容，通过特殊处理被引出来。
test.jpg


Anthropic 的发现
安全拒绝与语言连贯性之间的竞争
安全拒绝机制还在，但训练中另一个要求，是把话说完整。说到一半停下来会受惩罚，所以有时它沿着句子继续，就说出了不该说的内容。并不是拒绝机制完全失效，两种机制同时起作用，哪个更强，结果就不同。
有时它讲到一半又反思，出现“对不起，我不能继续提供这方面的信息”。这也说明两种机制在竞争。

LLM 的学习、推理与知识

LLM 的学习、推理与知识
第二讲准备的内容相对少一点，我也希望讲得快一点。有些内容，大家应该都熟悉，我们从另一个角度来看。
刚才说的两个问题，一是 LLM 的推理究竟是什么机制，怎样学习到的；二是知识怎样被表示、记忆、使用，又是怎样得到的。第一讲的可解释性研究，对知识这部分已经给了一些解答。
先说推理。中文里“推理”这个词容易混淆，英语有两个词，一个是 inference，一个是 reasoning。传统机器学习中的学习和预测，深度学习里经常把预测叫作推理，也就是 inference。我们现在更多讨论的是 reasoning，比如数学定理的证明，需要做这样的推理。
LLM 的 reasoning 到底是什么机制？一定程度上，看看它的 learning 和 inference，就能知道它怎样做 reasoning。

预训练、后训练、模型架构与推理能力的关系
我们复习一下：有预训练，也就是 next-token prediction；有后训练，包括 SFT、RL；模型是 Transformer，用梯度下降优化。我们看到的语言能力、推理能力，是所有这些要素组织起来产生的，包括训练目标、算法、Transformer decoder 的架构。

下一个词元预测、序列概率与压缩建模

下一个词元预测、序列概率与压缩建模
Next-token prediction 大家都熟悉。特别是外行，容易有一个误解，觉得它只是在算下一个词出现的条件概率。Transformer decoder 确实每次预测下一个 token，但根据概率的链式法则，每个位置的条件概率乘起来，就是整个句子、整个序列的概率。
学习时，我们学这些参数，使模型能够预测给定序列的整体概率。大家应该这样理解：展开来看，每一步是 next-token prediction；整体的序列，在我看来更重要。
test.jpg


下一个词元预测、序列概率与压缩建模
下一个词元预测与整个序列概率的链式分解
大家经常听人说，LLM 学习是压缩。它确实跟压缩有关：做 next-token prediction 的学习，等价于极大似然估计，也对应数据无损压缩的建模。如果不熟悉，可以自己再看。
比如 universal coding，通用编码，分两步：先对数据分布建模，假设能算出所有可能序列的概率；然后对序列编码，编码长度跟负 log p 对应，平均起来与熵有关。
假设有一个语言模型或者信息源，能产生数量极其庞大的 token 序列。我们算出它们的概率，概率加起来等于一，再根据负 log p 给序列编码。有各种编码算法，比如哈夫曼编码。
这里模型做的是学概率，预训练预测整个序列的概率。在通信的场景下，编码后再还原，数据可以完全还原，所以我这里强调的是无损编码。

下一个词元预测、序列概率与压缩建模
概率建模与无损压缩编码的关系
极大似然估计还有一个更重要的性质，叫一致性，或者这里说的近似一致性。图中考虑的是由模型参数定义的分布空间。真实分布在哪里，我们不知道，可以想象是“上帝给定”的、产生所有序列的概率分布。
给我数据，用极大似然估计，就能在模型规定的这一族分布里，找一个离真实分布最近的。这里“最近”用 KL 散度来衡量。在 KL 散度的意义上，它是这族分布里能够找到的最好的。
test.jpg


下一个词元预测、序列概率与压缩建模
极大似然估计在模型分布族中逼近真实分布
我们知道模型有多少参数，也就规定了一个分布族。参数可以取无穷多种值，对应无穷多个分布。真实分布不知道在哪里，但可以在模型的范围里，找一个离它最近的。这是极大似然估计的统计性质。
直观上，做完预训练，语言模型变成什么？给定上文，也就是 prompt，它产生的是“最有可能”的下文，是从见过的数据中学到的概率关系。实际也可能通过 sampling 产生结果。我这里说“最有可能”，是从条件概率估计、整体序列的角度直观理解。
模型学的是这些东西，统计意义上的性质很好。Next-token prediction 的说法比较容易讲，但我们还应该看到，它在估计后续整个序列的概率。
后训练与序列空间中的推理

后训练与序列空间中的推理
SFT 主要学习一些格式，这里先略过。后训练主要说强化学习，尤其最新的这些 LLM，强化学习起了非常重要的作用。
实际执行时，在 token 级别做强化学习。但我这样理解：在序列级别，也可以写出相应的强化学习关系，这样更容易理解。比如多轮对话、推理的多个步骤，一步可以是一句话、几句话、一段代码，也可以是一大段说明。
把这样一个序列当作一步的 action、输出，就可以从序列级别看这件事。现实里是在 token level 做，正则化项和一些细节会不一样。

后训练与序列空间中的推理
从词元和序列两个层面理解强化学习
这样理解有什么好处？可以认为 LLM 的推理是在 statement 的空间里寻找正确答案。Statement 是一段段话，也可能是代码、说明。强化学习时，我们可能只给出问题和最终答案，不给中间步骤，让模型自己学。
我的理解是，它在一个很大的搜索空间里，一步一步搜索。中间可能产生思维链，思维链也不一定正确。我们训练时，是让它找到最好的答案，让它学会怎样在语句空间里找。
test.jpg


后训练与序列空间中的推理
将推理理解为语句空间中的路径搜索
预训练找的是“最有可能”的整体序列；强化学习，在我看来找的是“最合理”的。这里的合理是什么意思？是平均意义上，输出最后获得的 reward 最大。
给定上下文，只找最有可能的下文，有可能完全不合道理。通过后训练，假设 reward 告诉它哪些是正确的、哪些不正确，就让它更可能给出正确结果。GRPO、PPO 这些方法，都是在平均意义上寻找更好的答案，实际实验也有近似。
在 token level 做，可以对应到序列 level 的理解，在语句空间里寻找最好的答案。SFT 告诉它格式：这样的输入，大概应该怎样输出；在相应条件下再做强化学习。数据和训练的设计，也很有讲究。
我举一个简化的例子，不一定就是现实中实际使用的完整版本。搜索答案的过程，可以在 system prompt 里要求：遇到问题，先分析，找一个答案，验证对不对；不对，再去找另一个，再验证；最后验证对了，再回答。

后训练与序列空间中的推理
系统提示中的分析、求解、验证与修正过程
设计后训练时，可以把这种要求放在前面。加上一些 SFT 的例子，包括思维链，它知道应该怎样回答。强化学习就去探索各种路径。通常有 verifier，验证结果对不对，让它学会更容易找到正确答案的路径，后续生成时再去做这样的事情。
这对应什么推理？它并不是数学上的逻辑推理，也不是贝叶斯推断那样的推理。我还不太好用一两句话概括：给定上文，输出最合理下文的整个过程，体现出我们说的推理。它可能是代码、对话，也可能是数学证明的过程。
预训练、后训练组织在一起，人用语言描述任务和过程，训练让 LLM 在平均意义上更合理、更准确地完成任务。有时要生成很多 token，一步一步做；有时一步就能做出来。这是 LLM 的这种推理机制，跟我们通常说的数学推理不完全一样。

训练目标、算法、架构、数据与工程共同形成推理能力

知识表示与自注意力

知识表示与自注意力
再说知识。可解释性研究涉及知识的表示、使用和激活。现在模型通常是 Transformer decoder。概念上，可以换成 LSTM 或其他模型，预训练、后训练的原理也可以用，但目前看到，跟 Transformer decoder 组合起来更有效。
Transformer decoder 的架构帮助模型更好地表示知识，后续用于语言表达和 LLM 的 reasoning。知识在哪里？很粗略地说，在 Transformer 的权重里，特别是 FFN，也叫 MLP 的权重里。

Transformer decoder 中的注意力、前馈网络与残差连接
Next-token prediction 是自回归、一步一步做的。每个 block 里有 self-attention、FFN，把知识学进去，再激活出来。Function token 能帮助激活隐藏的特征，我们第一讲已经看到。

知识表示与自注意力
自回归生成与多层表示的处理过程
这些机制都很重要，大家想过很多改进方案，现在常用的方案经过了考验。希望大家后面做研究，能提出更好的方案。
Self-attention 在做什么？我把它理解成 KV store 的检索。编程里很简单的键值存储，大家可能熟悉。假设 query 是 one-hot vector，一维是一、其他为零，key、value 也用这样的符号表示，就很像符号处理里的查询。
比如存人名、地址，我用人名查询，匹配上了，就把相应的地址返回，很容易理解。

知识表示与自注意力
以键值存储的检索理解自注意力
Self-attention 做的是 soft 的检索。Query、key、value 都是向量，不是 one-hot。Query 和 key 求内积，简单说就是看它们像不像，再经过 softmax 归一化，把相似程度乘到 value 上，得到加权结果。
它在整个网络中起的作用，是 composition。语言一个重要特点，是词组成短语，短语组成句子，句子组成篇章。这里的 attention 看前文，不能看后面，把前面已经生成的表示，通过这种 soft 查询组合成新的表示，再输出给下面的 FFN。

FFN 怎样记忆知识

FFN 怎样记忆知识
FFN 在做什么？记忆知识。结构非常简单，课间也有同学问到。现在也有很多变种，激活函数会换成更好的版本，但基本表示还是原来的样子。
每个 block 里是一个两层的 FFN，第一层有 ReLU 或它的变种，第二层是线性组合，没有再做 ReLU。大家感兴趣，可以讨论为什么这样更好。

FFN 怎样记忆知识
前馈网络的非线性激活与线性输出
深度学习中有万能函数近似定理，在一定条件下，神经网络能够近似连续函数。从函数近似的概念上说，两层已经够了。我们希望用更多层表示更复杂的东西，可以通过叠加 block，现在实际有几十层，甚至更多。
具体在做什么？输入 x，跟权重算内积，加上偏置，再做激活。权重表示的方向，跟输入越像，反应越强；同方向取大值，相反方向取小值。整个权重矩阵，每个部分都在看输入跟什么特征相似。
test.jpg


FFN 怎样记忆知识
以特征检测器理解 FFN 中存储的知识
再加上特征叠加，隐含地能表示更多特征。一个神经元可以认为对应特征的组合。输入跟这些特征越接近，反应就越强，它就记住这些重要的组合。不同层的 FFN，都在记忆这些东西。
说白了，它是 feature detector，特征检测器。把这些叫特征，容易跟前面特征叠加里的术语混淆，但它们密切相关。你可以把一个神经元理解成表示特征组合，知识大部分存在这些位置上。
为什么还可以扩展？比如 MoE，mixture of experts，就是把这部分扩展，让它更丰富。一般 FFN 的中间表示是输入长度的四倍或以上，也可以更长，通过这些方式记忆知识。
很多证据表明，知识主要记在这里。自注意力里也有变换矩阵，那些权重也重要，并不是只有 FFN，但主要的知识在这里。
残差连接、学习与知识获取

残差连接、学习与知识获取
残差连接也很重要。假设 f₁、f₂、f₃ 表示三层，也可以认为分别是 self-attention、FFN、下一层 self-attention，它们之间都有 residual connection。
相当于把不同深度的函数做一个 ensemble、组合，让各种深度的路径都包含在输出里。何凯明他们提出 ResNet，这种做法不光跟梯度问题有关，在表示的意义上也非常重要。
test.jpg


残差连接、学习与知识获取
残差连接组合不同深度的表示路径
比如随便举一个九十六层的模型，最后输出里包含各种长度的路径叠加。位置表示从输入层加进来，可以通过残差连接直接传到上面；底层一些很简单的特征，也可能直接影响最后输出。
这也是可解释性很难研究的原因。网络非常复杂，每层 self-attention 看到的，不仅仅是这一层本身的关系，还包含更早各层组合、传上来的表示。不能简单看某层 attention，就说只是这一层的关系。它也说明模型的表示能力很强。
学习的机制又很简单，通过随机梯度下降、反向传播，调整这些权重。特征叠加也能这样学出来。预训练做极大似然估计；后训练用 RL 的算法，使平均 reward 更大，去优化参数，最后网络就学到这些东西。

残差连接、学习与知识获取
知识表示、调用与通过训练获取知识
回头总结，自注意力做 composition，把目前已有的表示组合，再往下传；FFN 记忆知识；残差连接把不同层结合起来，再叠加很多层。经验上，这样的网络非常强大。
大家做过很多实验，看能否做得更好，有进展，也有很多变种，比如激活函数已经不再拘泥于原来的 ReLU。但最核心的思想和架构，到现在并没有改变。
知识存储在这些权重里，同时有 superposition，可以理解成存在潜在的 dictionary 里。预训练、后训练学到了什么，我们也大致说过了。

Ilya 很强调 next-token prediction 是核心，这有道理。但这个词，特别是对外行，可能产生误解，以为只是在猜下一个词。实际上是很多机制共同形成的能力。
我讲的是一个理解的角度，并不是只有这一个角度。我们觉得它好像人在思考、说话，但人自己是怎么回事，也还没弄清楚。刚才也看到，思维链有不准确的地方。我希望从这些机制，帮助大家理解它的推理和知识表示。
