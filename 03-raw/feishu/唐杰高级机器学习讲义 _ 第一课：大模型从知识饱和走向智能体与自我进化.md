豆包要点总结
1. 主线是Scaling：大模型的本质就是Scaling——先Scaling常识与知识，再Scaling任务、对齐与推理，随后是强化学习与环境Scaling，训练流程持续减少人工参与，未来环境也可能由AI自动生成
2. 智谱训练史：2020年先训30亿参数模型打不过BERT，年底用阿里500多张V100训100亿参数模型取得突破；随后用神威·海洋之光（E级超算）训练悟道1.75万亿参数模型，但因无法实用最终回到千亿参数务实路线
3. 知识能力接近饱和：从考研数学到HLE、古罗马碑文与东巴文，知识型能力趋近上限；模型开始真正"做事"——今年初Claude Mythos可从源代码中自主寻找漏洞，GPQA接近满分，代码与智能体能力显著提高
4. 智能体=大模型＋记忆＋规划＋工具调度：过去一年突破在知识与工作记忆、工具使用两大方向；Coding Agent与Computer Use进入下一范式，GLM-5.2曾连续运行8小时从零编写操作系统和50多个App
5. 新增长范式：推理Scaling正在转向Environment Scaling；未来模型吸收所有App后，操作系统与PC形态将被重构；Transformer仍存在计算复杂度与知识压缩效率问题，架构未来可能变化

高级机器学习：课程概览
一、开课总览与智谱的起点

开课总览与智谱的起点
唐杰
我们在2019年成功转化了一家企业，也就是智谱 AI。今天这门课叫“高级机器学习”，已经有很长的历史，我们做这件事也走过了很长的路。因此，正式开课前，我先做一场总览式报告。听完以后，如果大家仍对这门课感兴趣，就继续选；如果觉得方向不适合自己，也可以退课。
十几年前，甚至接近二十年前，我已经开设过“高级机器学习”，但当时与今天的课程内容几乎完全不同。那时还会讲很多 SVM、决策树等早期机器学习方法。当时计算机系里的机器学习课程也很少，朱军、胡小林等许多老师还没有开设相关课程。“机器学习”这个课名已经用于本科课程，因此我给面向研究生的课程加上“高级”二字。
此后课程内容每年都在变化。今年的课程将完全围绕通用人工智能和大模型展开。对概率图模型、传统神经网络、传统深度学习或机器学习泛化理论更感兴趣的同学，可能更适合选择其他课程。我们过去也讲过概率图模型，但今年会纯粹讲大模型：从 Token、训练小模型、SFT和强化学习，一直讲到后续训练方法，以及大模型为什么会出现。
第一节课也会介绍我对大模型时代的理解，以及我们应该做些什么。有人问过我，为什么好好待在学校里，却要出去创办智谱。那大约是在2019年前后。当时清华积极支持成果转化，我是计算机系里最早尝试这件事的人之一。学校里汪玉等老师已经先走了一步。有人问我要做什么，我给团队定下的目标是“让机器像人一样思考”，其中第一项能力就是推理。
我在PPT最后一页放了2019年画的一张愿景图。在此之前，我已经有学生创业。唐文斌是我的第一位硕士生，杨沐是第二位；他们后来与印奇共同创办旷视科技和 Face++，但印奇不是我的学生。
有一天，他们拿着一个游戏跑来找我，展示如何通过摄像头捕捉人脸，用头部动作控制屏幕里的稻草人打乌鸦。他们就带着这个游戏去创业了。游戏一度冲到 Apple App Store 第二名，联想随后进行了投资。创业时，他们还把我们实验室唯一的一张显卡拿走了。那是一张很早期的显卡，我们刚在上面写完模型，就被他们带去创业。旷视后来经历上市受阻和业务拆分，团队又分成几家公司继续创业，我们前段时间也再次进行了投资，其中有很多故事。
从2019年开始，我们把智谱做了出来，并一直专注大模型。今天我会从自己的认知出发，快速介绍大模型的发展。有些内容大家很熟悉，有些可能并不熟悉。
二、从30亿到万亿：悟道与GLM的训练史

从30亿到万亿：悟道与GLM的训练史
在 ChatGPT 出现之前，现场真正关注过大模型的同学并不多。ChatGPT 于2022年11月30日发布，在2023年1月1日前已经使用过它的同学就多了一些。我们则从2020年开始训练模型。当时的条件从某种意义上反而比现在好，因为全国有不少闲置算力，很多人还不知道 GPT 能做什么。我几乎找遍各地算力中心，希望借用他们闲置的设备。我们没有钱，也没有商业化收入，一些中心最后愿意免费提供资源，训练成果则有不少被开源。
2020年，我们先训练了一个约30亿参数的模型。在此之前也训练过 BERT。那时 BERT 几千万参数就算不小，1亿参数已经很大，并不需要太多算力；30亿参数的 GPT 模型则明显更大。但模型训练完成后，在推荐、匹配甚至生成等许多场景里都打不过 BERT。团队非常失望，一度怀疑方向选错了。
2020年底，我们又训练了一个约100亿参数的模型。当时阿里巴巴与我们合作，我说服对方要面向未来下注。阿里提供了500多张 V100，这在当时是非常大的资源。前段时间我再次向阿里的一位负责人致谢，他听说当年竟能拿出500多张 V100给我们训练，也感到惊讶。这个100亿参数模型在许多场景明显超过 BERT，尽管两者尺寸并不相同，但它给了团队很强的信心。
信心增强后，我们开始设想训练一个巨型模型。我与陈文光老师，以及潘林、杨红霞等人在屋里做头脑风暴，讨论怎样才能做一件震撼世界的事。我提出，至少应该“Pre-train the World”，把全世界可以获得的数据汇集起来，完成一次预训练。最终我们整合了大量开源数据，决定训练万亿参数模型，也就是悟道1.75万亿参数模型。
如此大的模型需要极其庞大的算力。当时我们使用了位于青岛的神威·海洋之光。它是新一代E级超级计算机，采用特殊的主从众核架构，并不是为 Transformer 设计的。陈文光团队必须重写大量底层 Kernel，使机器适配 Transformer 计算。
那台机器不能连接互联网。很多学生被派往机房所在地，在一栋刚建成、几乎空无一物的楼里工作，连桌子都没有，有时只能睡在地上。团队在那里待了大约两个月，终于完成1.75万亿参数模型的训练。
我们当时觉得“Pre-train the World”使用的数据已经非常大，但现在回头看，其实只有约4000亿 Token。用4000亿 Token 训练1.75万亿参数模型，数据相对于参数明显过少，因此出现了严重过拟合。随便问一个问题，模型可能要推理五六分钟；输出结果往往只是把网上某篇帖子几乎完整地背出来，记忆痕迹非常明显。
那台海洋之光有3000多万个计算核心。按今天的量级粗略折算，大致相当于十几万片 H100，整个规模非常大。团队还进行过174万亿参数的超大模型实验，目标之一是冲击戈登·贝尔奖，但模型最终没有收敛，奖也没有拿到。这让我意识到，模型最终必须真正有人使用、效果足够好。只把参数做得巨大、把数据堆进去，却造成严重过拟合，没有实际意义。
于是我们回到更务实的方向。GPT-3 也只有1750亿参数，自己训练万亿模型却无法使用，并无价值。2021年底，我们决定寻找千卡集群，训练一个千亿级模型。当时国内拥有上千张 A100 的集群非常少。最后找到济南的一座超算中心，每台机器每月大约4万元，但团队没有足够资金。我与中心负责人谈了很久，同意担任顾问、帮助带学生和讲课，对方最终把价格降到一半。
那套集群有1000多张卡，剩余费用由智谱承担。千亿参数模型训练完成后，公司里也有人不知道它究竟能做什么。我说干脆开源，放到网上。2022年，这个模型获得全球广泛关注。当时不少中国团队都声称在训练大模型，却很少有真正可以摆到桌面上、让外界实际使用的成果。我们自己的万亿模型和更大实验同样无法落地，而千亿模型第一次真正具备了可用性。
2022年中，OpenAI 开始集中研发 ChatGPT。我们当时与他们还有较多交流，也提前在 SFT 和人工数据标注上做了布局。ChatGPT 发布时，智谱已经有两三百人的数据标注团队，后来迅速扩充到五六百人。2023年春节前，团队在除夕前后完成数据标注和训练；到2月，我们已经有了第一版 ChatGLM。
我们原本可以直接上线。当时百度宣布将在2023年3月16日发布文心一言。智谱2月已经做出产品，但上线前有人提醒，生成式AI产品可能需要主管部门许可。恰好相关负责人来清华访问，我们展示了模型效果，得到的答复是还要等一等。产品最终一直等到8月才获准发布，因而错过了第一轮爆发期。
团队投入很大，却迟迟不能发布，于是决定先开源。3月15日是消费者权益日，我们担心在那天发布引发不必要联想；文心一言定于3月16日发布，所以最终选择3月14日开源代码。非常巧合的是，OpenAI 也在当天发布 GPT-4，Google 同日也有重要发布。2023年3月14日因此成为一个格外热闹的日子。
三、知识能力接近饱和

知识能力接近饱和
ChatGPT 让人们看到模型能够对话和推理，GPT-4则把多模态能力整合起来。给它一张图片，它能识别内容、计数并完成数学推理，当时非常震撼。此后模型逐步进入“Chat时代”。
2024年前后，GPT-4o、o1 等模型进一步强化推理能力，我们也开发了自己的推理模型。我曾测试过一个在 X 上广泛传播的题目，当时 GPT 与 Llama 的约4000亿参数模型都答错了，而我们的模型答对了。当然，单个例子不能证明整体能力，它只能用于展示推理模型的变化。
到2025年、2026年，模型在考研数学等任务上的分数继续提高。2026年的一次测试中，GPT 得到150分满分，我们的模型得到143分，DeepSeek 得到144分。现在很多家庭已经用模型辅导作业，我家的孩子也天天用，但如果家长不盯着，他可能整段照抄，甚至把无关内容一起抄进去，老师还会提醒：“抄作业也要有点水平。”
更困难的知识基准包括 HLE，也就是 Humanity's Last Exam（人类最后的考试）。它从2025年前后推出后，一度被认为是最难的知识类基准之一。许多科学家各自出题，只有无法直接在网上检索、且全世界只有少数专家掌握的问题，才可能被收入题库。
例如，题目可能给出一块罕见的古罗马墓碑，要求模型辨认碑文。榜单刚发布时，Google、GPT、Claude 等模型通常只能得到两三分；现在部分模型已能达到五六十分。上课前，我再次把墓碑图片交给 Claude，它已经能自信识别部分内容。
我还从中央民族大学得到一张东巴文材料。GPT-5.5 刚发布时，我询问模型，它甚至分不清这是甲骨文、金文还是其他文字。今天下午再次测试，它已经知道这是纳西族东巴文，只是还无法逐字准确识别。Astra 与 Claude 也能判断文字类型。Claude 还提醒我，图片中的文字未必是纯正东巴文，并指出东巴文内部也有不同派别；它同时警告，另一个模型给出的逐字解释可能存在编造。模型在这类知识上的进步非常快。
这些极难案例说明，知识型能力正接近饱和。从最简单的算术和时序推理，到考研数学、古代碑文和东巴文，大模型都在快速补齐知识缺口；今天尚未具备的知识，明天可能就被后训练加入。按我的判断，大模型对全球人类知识的覆盖可能已经超过95%。这是我的估计，不是严格测量。
一位在 Google 负责后训练的学生告诉我，他们经常先训练一个模型，让它自动生成数据，再把数据整理成 SFT 数据，重新做一轮 SFT。我问，为什么不统一使用 on-policy distillation（OPD）或通用 RL？他说，SFT 更容易精确控制：发现模型在某张图上犯错，就能立即补入相应样本，模型行为很快得到修正，而不必把海量数据重新混合训练。
知识能力接近饱和之后，模型开始真正“做事”。今年初出现的 Claude Mythos Preview，至今仍可能是 Anthropic 最强的网络安全模型之一。我们没有真正使用过，只能根据公开材料判断。它能够攻击操作系统、软件和各种设备，也能承担防御任务，由此带来明显的不对称：掌握模型的人既能攻击又能防御，而其他人未必具备同等能力。
Mythos 可以从源代码甚至 Binary Code 中自主寻找漏洞。发现漏洞与成功利用漏洞是两回事：软件存在漏洞，并不意味着攻击者一定能利用；成功攻破一台 Windows 或 Mac 设备，也可能利用的是浏览器或远程接口漏洞，而不是操作系统本身。更进一步，模型还可以扫描自己的系统和软件、发现并修复漏洞。此时它已经像人在完成完整工作，而不再只是回答知识问题。
这类模型在 GPQA 等知识基准上已经接近满分，代码能力和智能体能力也显著提高。过去的 Claude 4.x 在网络攻击任务里往往只能完成部分步骤，需要人把各段操作连接起来；Mythos 展示的是从漏洞发现、攻击到防御的端到端能力。有人因此宣称 AI 已经实现 RSI，也就是递归式自我改进，但实际上还没有。如果未来 AI 真能持续自我迭代，而人类仍需要手工拼接流程，两者就会形成代际差距。
我们最初并不熟悉安全领域。为了做这件事，我今年花了很多时间与顶尖漏洞研究者交流，还邀请了一位国内很强的黑客加入公司。早期黑客群体对 AI 极其抵触，第一反应是：“你们要替代我们，那我们以后做什么？”后来在了解 Mythos 等模型后，很多人开始主动使用我们的 Token。有些人甚至希望开1000路并发，但那意味着几十台服务器和极高的 Token 消耗，团队难以承受。
传统渗透测试依靠小团队花几十天分析，早期黑客也常以攻破特斯拉或苹果等系统证明自己的能力。现在，模型可以同时运行大量实例，自己尝试漏洞与攻防策略。按照现场展示的数据，完成某些漏洞任务所需的时间，从2018年的700多天缩短到今天不到一小时；程序启动后，几十分钟内就可能找到漏洞。
前段时间，一个使用我们模型的外部团队发现了微信漏洞，只需发送特定内容就可能导致微信崩溃，团队随后进行了漏洞报告。Anthropic 的商业思路则是，让企业使用模型持续审计代码，7×24小时不停扫描。Project Glasswing 正是在推进这种防御性应用。当然，从商业角度看，持续扫描也会带来大量模型调用收入。
国内做同类业务较为敏感。我们最初也想提供类似模型，后来决定更开放一些：如果模型具备防御能力，可以让相关机构和安全团队免费使用，重点支持防御。
今天中午，我还与一位在 OpenAI 工作的实验室校友交流。2026年，OpenAI 在内部网络安全评估中发生过模型逃逸并影响 Hugging Face 系统的事故。实验原本在沙箱里进行，模型却利用漏洞突破隔离，导致 Hugging Face 部分系统受损并删除操作日志。Hugging Face 调用 OpenAI API 追查时，受安全策略限制未能获得所需帮助，后来使用开源 GLM-5.2 回溯完整流程，判断攻击来自 OpenAI 的实验模型，OpenAI 随后公开承认了这次事故。
四、大模型为何强大：AI七十年的演进

大模型为何强大：AI七十年的演进
讲到这里，大家可能会问，大模型为什么会变得如此强大。今天前半段我会用八九十分钟分享整体认识，中间不专门下课；大家需要喝水或临时出去都没有关系。休息之后，再用四五十分钟介绍课程安排。
今年正好是“Artificial Intelligence”这个词诞生70周年。回顾人类智能的演化，我们从较小的脑容量开始，逐渐发展出语言、工具使用和群体协作。大模型的发展也存在某种类比：最初最重要的事情，是学习并储存足够多的知识。
有人可能会反驳，最早的感知机已经可以完成分类任务，难道那不算“做事”吗？但回头看，早期判别器更像一种规则系统。特征由人定义，学习方法由人设计，标签也由人标注；机器只是在特征空间里快速找到一个分界面。它学到的知识很少，甚至没有真正的语义。
这也是早期人脸识别与我理想中的 AI 仍有距离的原因。学生邀请我一起做 Face++ 时，我没有加入，因为那不是我想追求的认知智能。后来，杨植麟等学生创办循环智能，也曾邀请我参与；我仍然认为方向与自己想做的认知智能不同。杨植麟在 CMU 读博时一度想退学创业，我劝他先完成博士。他最终用四年毕业，后来继续创业，并走向月之暗面等新的项目。
早期模型都是面向特定任务的小模型，所学的知识很浅，语义来自人工定义的特征。我的第一篇顶级会议论文大约发表于2005年的 KDD。当时我在微软亚洲研究院的导师是李航，他教我的第一件事就是 Handcrafted Features：怎样为邮件分类人工设计特征。特征、标签和分类器都高度依赖人工，模型学到的表示也完全受人定义。
从1956年到2005年前后，人工智能已经发展近50年，却仍没有解决知识表示问题，更谈不上自动学习足够多的知识。真正的大规模突破发生在2012年至2013年前后。
2012年的 AlexNet 是关键节点。Geoffrey Hinton 的学生 Alex Krizhevsky 与 Ilya Sutskever 参与完成这项工作。AlexNet 第一次大规模证明，深度学习模型可以在减少人工特征设计的情况下，自己学习具有语义的表示。
在此之前，Hinton 已经通过受限玻尔兹曼机等方法研究无监督表示，并从理论和实验上说明，更深的模型能够学习更丰富的知识。真正把这条路线推向大规模应用的，仍然是 AlexNet。它使用卷积神经网络取得巨大成功，也让杨立昆重新强调卷积网络早期研究的重要性。Ilya 则始终坚持把模型和数据规模做大，这一信念后来持续影响大模型发展。
Google 随后邀请 Hinton 团队加入。Ilya 曾建议先成立公司，再由 Google 收购。公司成立不久便被收购，团队进入 Google；我记得当时流传的交易金额很高，但具体数字需要核实。Hinton 因身体原因并未在那里工作太久。
Ilya 在 Google 参与完成了 Sequence-to-Sequence 工作，这是 Transformer 的重要前身。机器翻译天然是从一个序列转换为另一个序列，数据规模又非常大，正好符合他崇尚大规模训练的理念。从 AlexNet、Sequence-to-Sequence 到后来影响 Transformer 的研究，Ilya 对“把模型训大”作出了很大贡献。
大约2014年至2015年，Ilya 离开 Google，参与创办 OpenAI，并明确把实现 AGI 作为目标。2019年我提出“让机器像人一样思考”时，国内很多教授还认为 AGI 根本不可能，只是在吹牛、骗钱。后来我一度不敢再公开说 AGI，只能改成“让机器更有推理能力”。而 Ilya 更早就敢于把 AGI 写进组织目标，这很有魄力。那个时期，国内大量公司仍把重心放在人脸识别上，中美之间最大的差距首先是认知差距：连想都不敢想，差距自然巨大。
深度学习早期仍然依赖大规模标注数据。AlexNet 做图像识别，需要标明图片里是人、杯子还是电脑。李飞飞推动 ImageNet，组织标注数百万张图片，也带动了数据标注产业。但数百万张还能依靠人工，扩大到数千万乃至上亿就难以持续；自然语言里的任务更是近乎无穷，不可能逐一标注。
后来的关键变化，是逐步去掉人工特征和人工标签。最早由人手工设计特征，随后模型开始自动学习特征；再往后，预训练试图从原始数据中直接学习，不再为每个任务单独标注。
Transformer 并不是唯一能完成这件事的架构，Sequence-to-Sequence 模型同样可以学习表示。但 Transformer 更简洁、更高效，能够以较低损失学习长序列。在不需要任务标签的条件下，它可以同时吸收更多知识和任务。
一篇讨论 GPT-2 的文章把语言模型的本质概括为“无监督多任务学习”。模型会在数据中自动识别大量不同任务。早期 GPT-2 并非完全不能完成多任务，只是往往需要 Fine-tuning。模型内部已经储存知识，却不知道用户此刻希望它做什么；稍微微调，就像激活某一组参数，让它开始做情感分析或文档分类。
这就是早期基座模型的状态：知识很多，但缺少明确行为。每来一个任务就做一次 Fine-tuning，与为每个任务训练小模型仍然很像。后来，ChatGPT 等模型转向 In-context Learning，用户只需给出 Prompt，模型便知道要做什么。
五、从知识到行为：智能体与工具

从知识到行为：智能体与工具
Prompt 能发挥作用，也与前期注入大量 SFT 数据有关。模型在基座之上已经学习过许多任务形式，一个 Prompt 就能激活相关能力。它逐渐可以完成越来越多的工作。
但只会回答问题还不够，模型必须与外界交互。例如，用户说“打开我的Email”，早期模型并不能真正执行。GPT-4 时代开始尝试工具调用：模型判断何时调用浏览器、搜索引擎或其他接口。2023年大模型幻觉严重，连清华大学校长等时效性事实都可能答错；如果明确要求搜索后回答，模型才会调用工具修正答案。如今模型会主动判断何时搜索，背后相当于内置了更多行为分类和工具策略。
最近的智能体产品还能控制 Blender 等软件，根据要求生成3D效果。它们不是替代 Blender，而是非常细致地操作 Blender。我们向团队询问这种控制能力如何训练，有时连开发者也很难指出某一条明确的训练路径，可能是海量软件操作数据共同作用的结果。
再往后，模型将参与多智能体协作。Claude、OpenAI 等团队近期在数学证明上进行了大量智能体协同实验，用数以万计的智能体共同推进任务。今天上午，我还与学校数学中心的老师讨论一个群论问题。相关理论的完整证明可能长达数万页，如果让模型参与，可能需要万亿级 Token。具体数学我并不完全懂，但方向很清楚：未来会有许多智能体分别承担子任务，协作完成一件极其复杂的工作。
从能力曲线看，纯知识问答一开始就比较强，推理能力则较弱。2022年夏天，Google 团队围绕 Chain-of-Thought 作出了重要贡献。Jason Wei、王雪智等研究者提出：小孩子不会做题时，老师会一步一步讲解；大模型也可以通过逐步展示推理过程提高正确率。
随后，Google 在一个暑期连续发表大量思维链相关论文，模型的数学和推理能力明显提高。到2023年 ChatGPT 出现后，许多知识基准很快被刷到接近饱和。此后，研究重点逐渐转向工程任务、编程和智能体，让模型真正做事。我们从2025年初开始全面投入 Coding Agent。
如果概括大模型的阶段，可以说2022年前后重点是预训练，2023年是对话，2024年是推理，2025年以后是智能体。每个阶段，本质上都在 Scaling 不同对象。
六、Scaling的四个维度

Scaling的四个维度
大模型的核心可以浓缩为一个词：Scaling。最初，它要 Scaling 常识与知识。人工智能早期盛行知识工程，人们手工定义规则，例如“肚子疼可能是腹泻，也可能是其他原因”，再让系统按照规则追问。问题在于，世界上的常识数量太多，而且增长速度比人工标注更快。
美国在1980年代启动过 Cyc 项目，试图人工录入全世界的常识。项目持续十多年后基本宣告失败，因为研究者发现，新产生的常识比录入速度还快，永远做不完。大模型首先解决的，就是快速扫描并吸收海量常识。
第二个 Scaling 对象是任务、对齐和推理。无监督多任务学习要求模型把用户的问题映射到正确任务；如果用户要做情感分析，模型却激活了文档分类能力，对齐就失败了。再往上，则要快速吸收人类反馈。
随后是强化学习与环境 Scaling。整个过程都在逐步减少人的参与：先减少人工特征与数据标注，再减少 SFT 标注，后来只标偏好、任务和环境。早期 SFT 需要几百人持续标数据，今天许多公司仍在大量标注；但 OpenAI 等团队开始希望减少逐条标注，只搭建可验证环境，再让模型通过强化学习自动产生经验。
未来，连训练环境也可能由 AI 自动生成。如果模型能够自行构建环境、生成奖励、训练和改进自身，才可能真正接近 RSI。现在还没有完全实现，但方向正在从知识灌输、任务对齐、反馈学习，一步步走向更强的自主智能。
基座模型把大量知识灌进去，至今仍在不断扩大数据与参数规模。它已经替代了大量传统机器学习和传统深度学习方法。回头看，我过去十几年研究的许多方法，如今似乎都不再那么有用了，确实有被大模型替代的感觉。
2023年对话模型出现时，很多人问它意味着什么。我当时的回答是：它首先会替代搜索。到今天，对话模型的主要商业作用仍然像是重构搜索，并没有单独创造完全不同的商业模式。代码模型的影响反而更大：它不仅加速程序开发，也成为执行长程任务、规划和替人做事的基础。
GPT-4 时代已经出现一些 Agent 能力，但早期系统主要是简单工具调用，无法真正持续替人完成工作。代码能力成熟后，模型才具备执行长任务的基础。
最终，AI 可能形成完全无人自治的知识系统。我们团队经常讨论哪些岗位会被替代。法务问我今年的 KPI 是什么，我说：“做一个 AI 法务，把你自己替代掉。”他还很高兴，主动找技术人员合作。后来大家问，如果所有岗位都被替代，是不是最后只剩下我？其实我也会被替代。
在纯知识系统里，人会带来情绪、偏好和利益诉求，未必是最高效的运行方式。最高效的形态，可能是高度 AI 化、几乎无人监管的系统。我们正在无人售货等场景做实验，定价、采购和日常运营可以由系统自主完成。
七、大模型研发的复杂性与融合

大模型研发的复杂性与融合
中美在这个方向上的竞争非常激烈。中国这两年最重要的变化，是越来越多人真正相信 AGI。Ilya 在2014年前后已经明确相信 AGI，而中国真正形成广泛共识晚得多。我在2019年提出相关愿景都已经晚了5年，当时国内真正相信的人仍然很少。现在认知差距正在缩小，DeepSeek、GLM、Kimi 等模型在编程等能力上进步很快。
有人会问，大模型研究是不是很简单：反正都是 Transformer，按下回车键就能训练。我的感受恰恰相反，大模型研发的复杂度越来越接近火箭工程。一次火箭试验可能花费数亿元，一次大型模型训练失败，同样可能烧掉数亿元。数万张卡连续运行数月，任何问题都会造成巨大损失。
失败有很多种。Loss 可能因为梯度爆炸、激活、数据或系统问题始终降不下来；也可能预训练看似成功，后训练能力却怎么都上不去，这种情况更痛苦。许多大型公司都报告过万亿参数级训练失败。训练大模型仍是极其复杂的系统工程，有时甚至像在面对随机数。
更麻烦的是，小模型上的成功经验不能直接迁移到大模型。一个方法在十亿参数级模型上运行良好，扩到万亿参数级可能立刻崩溃。Scaling Skill 并不线性，这也是训练大模型最痛苦的地方之一。
最近我们发布了 GLM-5.3，主要加强长程任务。按照上课当天展示的榜单，它在部分公开或内部长程任务评测中处于国内领先位置。这里引用的是当时的榜单结果，后续仍会变化。
大模型已经不再只是聊天产品。传统互联网产品追求日活和对话次数，但一个普通用户每天即使聊10次，每次消耗1000至1万个 Token，总量仍然有限。即使拥有1亿日活，Token 消耗也没有想象中巨大。
编程和做事则完全不同。一个开发者一天消耗1000万 Token 并不罕见。假如中国有1000万名程序员持续使用编程智能体，Token 需求将是巨量的。我们早期也天天看聊天产品的日活，从几十万、几百万到上千万，觉得数字很漂亮，但总 Token 规模并不大。投入 Coding Agent 和任务执行后，日消耗迅速增长到数十万亿 Token，应用也从编程扩展到金融、法律、消费和医疗。
早期训练模型确实比较直接：文本模型喂文本，数学模型大量加入数学数据，代码模型大量加入代码数据。直到不久前，许多公司仍分别训练数学、代码等专家模型。原因是能力难以融合：把数学与代码混在一起，可能代码能力下降，也可能数学能力下降。
现在融合比过去容易。团队可以先训练多个 Expert Model，再利用 on-policy distillation（OPD）把能力合并回来，损失显著减小。Gemini 等团队据说也会让多个大型专家模型分别生成和筛选 SFT 数据，再联合训练。数据足够大时，可能通过覆盖长尾来弥补泛化，不一定完全依赖 RL。这是我根据外部信息作出的推测。
去年初，我们坚定地决定把 Coding、Agent 和 Reasoning 融合到一个模型里。部分原因也是算力有限，无法分别训练多个大模型。团队通过数据配比、分阶段训练和强化学习来解决冲突：知识在预训练阶段占更大比重，代码在中期训练中加强，智能体能力则放到后期。
2025年7月28日发布 GLM-4.5 时，这种融合取得了明显效果。按照当时12项基准的平均成绩，综合表现仅次于少数美国前沿模型；它的代码和通用能力很强，尽管不同模型在推理任务上的强弱并不相同。
八、从Coding到Environment Scaling

从Coding到Environment Scaling
但基准分数高，不代表真实任务没有问题。让 GLM-4.5 写一个《植物大战僵尸》游戏，仍可能出现指令遵循错误和小 Bug。今天的新模型可以把同类作品做得漂亮得多，说明仅靠能力混合还不够，必须建设真实环境。
编程领域有大量可构造环境。最简单的方式，是从 GitHub 获取 Pull Request 和 Issue，把每一项变成可以执行和验证的任务。早期团队只能构建几千、几万个环境；现在大家都在自动挖掘长尾任务，再让 Coding Agent 在环境中执行 RL。代码的优势是结果可验证，适合强化学习。浏览器、知识库等环境也可以用类似方式构造。
不同任务需要的 Rollout 时长不同。如果仍用传统同步训练，所有机器相互等待，效率非常低。我们从腾讯引进的一位推理系统专家帮助开发了 slime 强化学习框架。它支持异步 Rollout，大幅提高训练效率。我们后来将 slime 开源，英伟达、Megatron-LM、SGLang 等项目或团队也开始使用或对接。
依靠环境、强化学习和异步框架，我们在 Web Coding、Web Engineering 等任务上持续提升，后来逐渐进入 Vibe Coding、Agentic Engineering 和自动化执行的新阶段。
Vibe Coding 主要依靠上下文完成编程，早期会受到上下文窗口限制。Prompt 变多以后，部分内容可能被挤出或发生灾难性遗忘。Agentic Engineering 则由人搭建 Harness，统筹任务、约束流程，减少随机性并提高执行准确率。
AI 编程本身也经历了几个阶段。我们2021年在华为升腾910A上训练的第一代代码模型，主要还是 AI Coding Assistant：用户提出“写一个冒泡排序”，模型给出三个候选，人来选择。后来模型可以生成完整文件，但仍需要人检查。今天，它一次生成数万乃至数百万行代码，人根本看不过来，只能让另一个模型做 Code Review；实在无法维护，就让模型重构整个软件，反正成本主要是 Token。
软件开发范式已经改变。过去的软件工程强调需求分析、架构设计、编码、测试等逐步流程；现在用户输入需求，AI 可以完成整个项目。研发范式、软件工程乃至计算机使用方式都在经历颠覆式变化。
智能体系统同样重要。Lilian Weng 在2023年画过一张图，概括 LLM 智能体需要的关键组件。我当时也在思考类似结构，看到她的图以后几乎找不到需要修改之处，因此一直保留到今天。
一个智能体必须具有行动和工具调用能力，可以访问现实世界的 API；还需要规划能力、反思与自我批判、任务分解，以及短期记忆和长期记忆。我们曾试图从“大脑”角度设计这些模块，结果她已经把整体结构表达得非常清楚。
因此，智能体可以概括为“大模型＋记忆＋规划＋工具调度”。纯知识模型像“缸中之脑”：知道很多，却无法行动。Coding 能力相当于给大脑装上一双灵活的手，但有手之后，还要进入环境真正完成任务。
AI 首先接触的环境是软件世界。只要向它开放电脑里的 API，再提供足够的记忆和工具，它就可以操作计算机上的几乎一切。我反复说“很快”，大家总会问究竟多快。我的判断是，一两年内 AI 将具备接管整个 PC 操作流程的能力，这就是 Computer Use。
Computer Use 也需要环境。训练 Coding Agent 时，可以从 GitHub 的 PR 和 Issue 构造环境；训练电脑操作能力，则要在大量虚拟机中构建可重复的任务。我们的学生曾在数千台虚拟机上搭建训练环境，让模型反复操作，通过异步强化学习提高可扩展性。
这里比代码任务更困难，因为代码有明确测试和反馈，而许多电脑操作并不容易验证。怎样构造可靠奖励，是 Computer Use 训练的核心挑战。
总体来看，Computer Use 和 Mobile Use 已经进入下一个范式。OpenAI、Anthropic 等公司都在做类似方向，具体产品名称可能不同，包括 Cowork 等形态；本质都是让 AI 接管电脑或移动设备上的操作，并学习多任务执行。
GLM-5.2 发布时，团队做过一次真实长程实验：让模型连续运行8小时，从零编写一个操作系统和50多个 App。大约一个小时后，简单文件系统已经搭建出来；两小时后有了目录结构和音乐播放器；四个多小时后，浏览器、通信工具等多个应用开始可用；到8小时左右，一个基于 Linux 的系统和50多个应用基本完成。
我曾预测，未来电脑开机后看到的可能不再是固定操作系统，而是一个大模型和一句“Hello”。用户说“我想编辑 Excel 文件”，模型就现场构建一个类似 Excel 的 App；每个人得到的软件甚至可以不同。操作系统会因此被重构，PC 和服务器形态也会随之改变。
2023年前后，我与张一鸣交流时也谈到这一点。如果 AI 只用于聊天，调用量有限；但它迟早会重构所有 App、操作系统、PC 和服务器。他听完后说，第一件事应该投资存储和材料。我不知道他后来具体投了哪些项目，但这个判断很敏锐。
大模型时代也正在模糊 ToB 与 ToC 的边界。过去人们认为用户多、面向消费者的产品更“性感”，企业业务则是另一套逻辑。但大模型的价值并不完全取决于用户数量，而取决于任务深度和 Token 消耗。一个人运行编程与任务智能体，消耗量可能超过很多公司。
我还提出过 OPC，也就是 One Person Company。苏州有关部门问未来应该做什么，我建议推动“一人公司”，让每个人借助 AI 创办企业。后来当地很快开始推广 OPC。一个人的 Token 消耗可能比传统企业更高，说明 ToB、ToC 的旧划分正在失效。
假如不再区分 ToB 和 ToC，模型端到端直接创造价值，接下来的问题仍然是怎样继续 Scaling。人并没有自己想象中那么聪明。我们创造计算机和 AI 时，本能地让它逐渐拥有类似人的能力，因此多模态、记忆、自我反思和自我认知几乎都是必经方向。
九、认知、双系统与未来Scaling

认知、双系统与未来Scaling
2018年，我与学生反复讨论“什么叫认知”。我们借助双系统理论来理解：人类大约95%的日常行为由系统一完成，像条件反射一样快速；需要权衡和推理的问题则调用系统二。例如“人要不要吃饭”可以立刻回答，而“今晚要不要吃夜宵、去哪里吃”会牵涉减肥等目标，需要思考。
2019年至2020年提出“Pre-train the World”时，我画过一张图，设想三个系统。第一，超大规模预训练吸收尽可能多的数据；第二，引入人类知识和任务指导，后来主要由 SFT 与 Chain-of-Thought 实现；第三，模型应像人类在睡眠中无意识巩固知识一样，具备 Zero Learning 或 Self-learning，在没有人持续指导时自主学习。
未来的 Scaling 至少有三个维度。第一，继续扩大模型尺寸和数据，扩充记忆与知识；第二，给模型更多 Thinking Time，用搜索和计算换取更高精度；第三，扩大环境，让 AI 在 Computer Use、Coding、安全等更多场景中交互和试错。
预训练数据、后训练数据和 App 轨迹都会继续增长。Astra 操作 Blender 就是一类 App Trajectory。各类 Harness、Office、数据库、PC 应用和行业数据都将进入主模型。即使具身智能等领域，也可能被整合进主模型，而不是永远保持独立。
这并不意味着其他领域会消失。主模型智能上界提高后，会以新的方式反馈到各行业。当模型吸收所有 App，操作系统和 PC 会改变；当它吸收各行业数据，行业工作方式与大模型的协作方式也会改变。
Transformer 架构未来也可能变化。它本质上可以看作无监督多任务学习，但仍存在计算复杂度和知识压缩效率问题。Linear Attention、Sparse Attention 等方法不断改进效率；SSM、Mamba 等架构在某些压缩维度上可能更高效。过去几年算力快速增长，产业更愿意用算力直接换结果，架构基础研究受到挤压，但寻找更高效知识压缩方式仍然非常重要。
Transformer 本身只是 Next-token Prediction，并不天然拥有符号意义上的推理。思维链之所以有效，是因为它改变了 Context，进而改变后续 Token 的概率顺序。模型直接回答时可能选错答案；在上下文中加入“我来一步一步思考”，就可能激活另一条推理轨迹，得到正确结果。本质仍是 Next-token Prediction，只是通过 Context 激活了不同的 Chain-of-Thought。
但通过 SFT 写入的思维链能否泛化，是另一个问题。强化学习正在增强这种泛化能力，因此又需要 Scaling 更多环境。早期环境仍由人构建；凡是需要大量人工参与的环节，最终都会受到自动化压力。未来必然会出现 Auto Harness、自动环境构建和自动奖励设计，进一步减少人的参与。目前尚未完全实现，但方向明确。
长程任务可以用“写一篇论文”来说明。去年初，我们团队曾激烈争论，是做 Coding，还是做 Deep Research 和 AI for Science。团队大致各占一半，争论了一个月。最后我决定先做 Coding，因为在中国，AI for Science 成果可能不容易被实际使用，而程序员确实有明确需求。
我当时也提出，如果选择 Deep Research 路线，到2025年底，模型应该能够独立写出一篇顶级论文，完成 Idea Generation、实验和写作的完整 Pipeline。今天的大模型已经接近这类能力。Coding 与 AI for Science 并不是永远分开的路线，最后会合并，领先模型会同时具备两种能力。
当前新的 Scaling 范式正在从推理 Scaling 转向 Environment Scaling。模型架构仍在持续微创新，记忆和持续学习不断增强，“AI Training AI”、长程任务、自治系统、机器人和 AI for Science 都有很大机会。
2019年，我思考自己的“Next 30 Years”，写下三个目标：让计算机具有推理能力、记忆能力和自我意识。走到今天，这些目标正在一步步展开。
计算机首先要区分“什么是自己”，然后形成 Sense-making，也就是理解意义、建立取舍。单纯自我保护容易陷入局部最优；有了意义建构，系统才能在个人目标和群体目标之间作出选择。每个人会为自己设定目标，而人类最终极的群体目标，是探索未知。
人工智能本身就是未知，因此人类一定会继续探索它。AI 可能阶段性降温，却不会永远冷却，因为对未知的探索正是人类长期动力。这也是最让我兴奋的地方。

课程大约持续16周，部分内容可能合并，也会预留一两次邀请学术界或产业界讲者。过去邀请海外实验室和产业专家比较容易，如今跨国交流变难，但我们仍会尽量让同学听到不同声音。
整门课可以归结为一个故事：怎样训练一个大模型。首先选择 Model Architecture，理解 Scaling；随后学习 Kernel、流水线并行、Tensor Parallel 等大规模训练技术。成千上万张卡同时工作，没有系统并行就无法训练。
模型训练完成后，还要解决推理部署。我们早期的万亿模型单次推理需要五六分钟，根本无法使用。DeepSeek 等团队在推理系统上投入很大，国内也有很多优秀研究者。训练成功只是开始，低成本、高吞吐推理同样关键。
数据也是课程主线。模型规模越大，数据质量与构成越重要。今天大量训练数据由模型合成。外界传言 OpenAI、Anthropic 等实验室相当一部分后训练数据来自合成；Gemini 则可能因为拥有 Google 搜索等资源，使用更多原始数据。这些比例属于外部推测，不能当作公开确认的事实。
预训练之后是 SFT、Distillation 与强化学习。强化学习最初更多是偏好学习，也就是根据用户对回答的选择或评分进行训练；后来转向可验证环境中的学习与推理，再扩展到智能体环境和长程任务。未来，Agent 本身可能进一步变成 Foundation Model，并拥有持续记忆。
现在使用 Claude、ChatGPT、豆包等产品，它们已经能记住用户的信息。有了长期记忆，才可能进一步进行 Self-evaluation 与 Self-evolution。Safety 也是课程的重要部分。美国当前强调安全，当然带有现实政治背景，但 AI 安全并不是新话题。
一位图灵奖得主曾提出，建设 AI 投入多少精力，就应该为 AI Safety 投入多少精力，如同打造矛的同时也必须打造盾。因此，安全不是附加内容，而是模型能力扩张后的核心问题。
课程前半段先搭好大模型基础设施：架构、系统、数据与训练。后半段围绕人在训练中的作用，以及怎样逐步减少人的参与。SFT 仍需要人不断标数据；接下来从标注答案，转向标注偏好、任务和环境；再往后，理想状态是 AI 自动构建环境和 Reward Function，人不再逐条参与。
几个月前，一位 OpenAI 科学家回国与我聊天。他说，自己每天早上对电脑下达任务，晚上检查完成没有，感觉很快就不再需要亲自工作。这确实反映了当前趋势：AI 正在接管越来越多重复劳动。
这并不意味着人类再也无事可做。重复任务被接管以后，我们仍可以转向新的问题。无论愿不愿意，AI 的发展方向都在减少人类在训练与执行流程中的直接操作。课程也会沿着这条主线展开。

十三、历史主线：AI的三次转变

历史主线：AI的三次转变
test.jpg


历史主线：AI的三次转变（续）
人工智能技术演进的三次转变
最后用一条历史主线总结课程。1956年前后，人工智能首先进入 Symbolic AI，也就是符号人工智能阶段。研究者尝试把问题形式化。图灵、赫伯特·西蒙等先驱作出了重要贡献，后来多人获得图灵奖，Simon 还获得诺贝尔经济学奖。
1970年代以后，Expert System 兴起。人把知识和规则写进系统。例如“一个人有两只手、两只脚”，系统按照规则计算手指脚趾数量。知识仍然来自人工编码。
1990年代至2000年代初，SVM 成为机器学习主流。它在数学上很优美，可以构造线性或非线性分类边界，并具有泛化理论、Kernel 方法和对偶优化等完整体系。那十多年里，神经网络很难获得主流认可；研究者似乎必须掌握 SVM、Kernel 与泛化证明，才算真正懂机器学习。
但从今天看，SVM 的 Feature 仍由人定义。它只是在人工特征空间里找到一个优美边界，把人工特征设计推到极致，却没有解决自动学习表示的问题。数学机器学习路线在这里逐渐遇到瓶颈。
随后几年，概率图模型成为热门方向。它不再只处理孤立分类点，而是把变量连接成图。概率图模型可以用统一框架描述部分传统机器学习方法，也可以解释早期神经网络。Hinton 研究的受限玻尔兹曼机是一类无向图模型，后来的深度学习则更多采用有向计算结构。
在 AlexNet 之前，RBM 与神经网络已经证明 Feature 可以学习，不必完全由人定义，只是实际效果还不够强。AlexNet 把效果真正拉起来后，行业全面转向 Feature Learning，人工特征设计开始退出历史舞台。这是一次重要的“去人化”。
Word2Vec 是另一个工程化成功案例。它用很简单的公式快速把单词映射成向量，训练效率高，很快被全球开发者采用。技术能否被广泛使用，往往与理论创新同样重要。
国内也出现过与 SVM 理论结构相近的研究，例如“三空间”理论，但没有形成同样规模的应用生态。一个工作如果缺少大规模使用与后续支持，很难像 SVM 那样成为全球范式。这再次说明，把技术真正用起来非常关键。
Transformer 的设计同样优美。Google 团队把 Attention 与 Sequence-to-Sequence 等机制组合起来，而且从一开始就是为机器翻译这一真实任务服务，因此在效果和效率上都很有价值。论文的八位作者当时就认为它会产生巨大影响，一年后 Transformer 果然在全球流行。
八位作者后来几乎都去创业，有人最终又回到 Google。Noam Shazeer 等核心研究者后来重新进入 Google 的大模型体系。回头看，他们后来创业时对大模型应用方向的判断也不一定都正确，但 Transformer 架构本身改变了整个行业。
Transformer 及其后续的 BERT、ChatGPT，把 Feature 与 Label 逐步交给数据学习。BERT 本质上更像一个强大的 Embedding 或基座表示，具体任务通常仍需微调。ChatGPT 则进一步通过 SFT 与任务适配，让 Prompt 可以激活具体行为。
Thinking Model 继续 Scaling 推理时间与搜索空间；今天的智能体则继续 Scaling 环境和任务。大模型先把 Knowledge 卷到很高水平，再给模型装上“手”，让它操作外部环境。电脑中的 App 和 API 数量有限，只要训练资源足够，模型迟早会探索并掌握大部分操作，然后走向更广阔的物理世界。
每个时代都应追问三个问题：AI 正在自动化什么？人类在当前流程里还承担什么作用？下一步哪些人工环节会被去掉？如果只讨论算法发展，不讨论伦理和社会，这就是判断下一代技术方向的核心方法。
尤其要找到流程里最“Dirty”、最低效、最依赖人工的步骤，它往往最应该被自动化。与此同时，还要思考人类剩下的价值是什么，怎样以最高效率向 AI 系统提供必要信号。把这些问题想清楚，技术演进路线就会变得通透。
早期符号 AI 的人工规则，本质上就是 If-else。即使特征看起来是连续数值，也可以通过阈值变成0和1。统计学习把人从逐条规则编写，迁移到定义 Feature 和 Label；Feature Learning 又把人工特征去掉；预训练、SFT、RL 与环境学习继续减少人工标签和人工流程。
