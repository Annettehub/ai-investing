一、监督学习：样本、特征、标签与模型
监督学习的训练、评测与测试流程
在有监督学习中，每个输入样本都对应一个标签 y。标签可以是标量，例如 0/1，也可以是 1 到 k 中的一个类别值。模型要学习的，就是从特征到标签的映射参数。
学习的过程就是学习一个模型。很多人会问，model 是什么意思？模型说白了就是一些参数，当然，不同机器学习方法中的参数含义各不相同。训练过程中要评测模型，既要看与训练数据同分布时的表现，也要关注不同分布下的表现。
比如在学习过程中计算 loss，其实是同分布评测。但最终评测要单独划出一个样本集，这些样本在 training data、训练集中没有出现过。严格意义上一点都没出现也不可能，总有两个样本偶然碰到一模一样的 distribution。训练集与测试集不应完全不同，否则训练和测试任务发生错配；也不能把测试集直接放进训练集，否则模型可能只是记住题目，在榜单上得分很高，实际体验却很差。
把 test data 放进去，理论上可以把分数刷得特别高，最简单的办法就是背下来。但实际效果肯定不好。

二、回归、曲线拟合与损失函数
多项式曲线拟合
图里有 X 轴、Y 轴。采样以后，X 轴是采样点，Y 轴是测量值，蓝色的点是输入样本。最简单的办法是回归出一个方程、一个函数、一条曲线。现在给一个新的值、一个点，就可以通过回归函数计算 Y 值，也就是预测 Y 值。
所谓学习也就这么简单。对于这张图，假如把绿色的线抹掉，你不知道曲线长什么样，只给你10个点，就没那么容易生成一个 perfect 的函数。为什么？
因为你不知道曲线是几次函数、几阶函数，也不知道它是不是这样的多项式函数。给你一个方程，M 值取多少也不知道。这里有两个问题：首先，是不是多项式函数、方程应不应该写成这样，你不知道；其次，M 值取多少，你也不知道。
假设知道它是多项式，而且 M 等于3，最后要求的就是 w0 到 wM，共4个参数。知道了函数形式，剩下四个参数要学习，这是早期的机器学习。现在始终把问题映射到 Transformer，又是什么呢？
还是原来的函数。现在动不动要学1万亿参数，这里学的一个参数，就是1万个参数中的一个。所谓机器学习就是这么简单。有1万亿个类似的参数，问题就是怎么学习它们。

二、回归、曲线拟合与损失函数
最小二乘损失函数
怎么把1万个参数全部呈现出来、核算出来？这是一件很简单的事。拟合过程的逻辑也很简单：在任何一个样本点上，绿色的线是拟合函数，线上对应的点是预测值，也就是通过函数算出来的值。
真值是 yᵢ，也就是白色的圈，中间红色的 gap 就是误差。你可能会说，上面的值测错了。先不管测没测错，训练集中总有数据是错的，这毫无疑问。假如训练集中所有数据都错了，就没法学习；我们只能假设数据基本上都是对的。无论如何，对这个点来讲，两者之间就是它的误差。
把所有 n 个点的误差加在一起，就是整个误差。我们希望误差越小越好，机器学习的目的就是让误差越小。

二、回归、曲线拟合与损失函数
零阶多项式拟合
刚才的多项式函数可以变一变。假设不知道函数形式，先把它变成零次，m 等于0。这时函数退化成一条与 x 轴平行的直线，只能上下移动，因为它只有一个参数。
0阶模型只能上下移动，放到训练误差最小的位置时，输出接近样本均值。它虽然简单，但训练误差较大。机器学习要在简单与复杂之间权衡：模型过于简单会表达不足，增加探索又会提升复杂度。RL 与 Scaling 也面临这种取舍。
从计算机的角度看，机器学习始终希望一件事越简单越好，因为简单才容易 Scaling。计算机本质上就是二进制代码。但简单以后，如果不做 RL，不去 Explore、不去探索，又会怎样？
模型就停在这里了。它太简单，不能覆盖所有参数、数据。这时总要做额外的 Exploration，使模型变得复杂。所以从本质上，我们讨厌额外的探索，包括做 RL 时额外的 Exploration。

三、过拟合：数据规模与正则化
不同阶数多项式的参数系数
从数值上看，0阶、1阶、3阶和9阶多项式模型的复杂度依次增加。为什么9阶模型看起来更差？0阶模型只有一个参数，表达能力有限；9阶模型表达能力很强，但训练样本只有10个，容易过拟合，导致参数值很大、泛化较差。
九阶的表征能力很强，肯定大于三阶、一阶和零阶。但训练样本太少，就会 Overfitting，使训练出来的数值非常大。从数学角度看，每一维的值、偏方差都很大。
只有10个参数、10个样本时，拟合出的参数可能很大，模型容易过拟合。可以用两种办法处理：增加数据，或通过正则化限制参数。
这就不好。上节课给大家讲过，2021年我们发过悟道1.75万亿模型，也就是悟道2，大家可以去看。它在一台超算机上训练，有1.7万亿参数，当时数据集只有4000亿 Token，却要训练一个1.75万亿参数的模型。
这个模型确实过拟合了。比如问“清华大学校长是谁”，它可能背出网上的旧帖子；即使校长已经更换，模型仍会复述旧内容。
后来我们做了两件事：第一，赶紧清洗数据、加数据；第二，把参数降到1000多亿，训出了1300亿模型。模型非常不错，能用、很实用。后来数据集越来越大，现在大概快接近四五十T，也就是四五十万亿，还没到。
美国那边应该是我们两倍到三倍的体量，更大。像 Facebook、Microsoft，号称已经训到10T，而且有明显往上涨的趋势。当然，参数量上涨有很多因素，不是单纯数据量大，参数量就要大。
因素很多，比如用 FP4、FP8 还是 BF16 训练，要不要做 Loop。我上次讲过，回头还会再讲、再 Comment。假设所有情况都不变，像刚才的 Case，第一个办法就是加数据。

三、过拟合：数据规模与正则化
增加训练数据：一百个样本
相当于把中间有些点拉回来了。结果虽然还没那么好，但明显好得多。如果再把数据增大到100，用100个样本学习10个参数，这条线就比刚才三阶学得还好。我用最简单的机器学习给大家看大模型：参数量不变，数据量逐渐增加，模型的 Performance 就会逐渐变好。
接着问，能不能再增加到一两百、300、1000个样本？我也不一定能说。比如现在 Loss 已经降得很低，再加100个样本，可能只再掉0.01%，掉不了多少，收益就很小。
对大模型来讲，我们也不会疯狂增加数据。国内很多团队，包括 Kimi、DeepSeek，也不是疯狂往上堆。没有数据吗？也能找得到。但数据和参数相辅相成，玩命单方面增加数据，或者单方面增加参数，都有问题。
另一个问题是，增加太多数据可能不划算。再增加100个样本，可能只提高1%，计算量却提高2倍，原来训两个月，现在训四个月，值不值？肯定不值，所以要做很多选择。早期机器学习像这样的样本，看得见，可以做十组、100组实验。几十年前还有一个很著名的分支，叫 AutoML，也就是自动机器学习。
自动机器学习就是让程序自己做这些选择，当时还不叫 AI。大部分做法是让程序自己跑一遍：100个样本跑一遍，90个、80个、110个各跑一遍，发现变化不大就停。这消耗大量计算，但当时计算量都很小，可以跑。现在到了大模型时代，就没有那么多试跑机会。最近很多人也观察到，我上节课提过，超大模型的训练范式跟小模型不同，甚至上T的模型与几千亿模型的性质、表现都不一样。
于是，几百亿、几千亿模型上得到的经验，放到更大的模型上可能不对，一训就崩。现在很多上千亿模型都崩了，不是一家两家，而是很多家都有各种问题。训练超大模型需要非常细腻的判断，做很多 A/B 测试等相关工作。

三、过拟合：数据规模与正则化
正则化：惩罚过大的参数
这是第一个办法：增加数据。第二个办法是正则化。参数值特别大意味着函数斜率变化很大、曲线很陡；要让拟合曲线接近绿色的真实曲线，就需要减小斜率，也就是限制参数值。做法是在原有 loss function 后加 penalty，促使 w 变小：前一项最小化预测误差，惩罚项限制参数规模。
让斜率变化小一点，说白了就是让数值小。怎么让它小？原来的 Loss Function 不变，在后面加一个 Penalty，逼着 w 变小。前一项 Minimize Loss，使预测误差越小越好。
再使惩罚项的值越来越小，w 值自然就小了。

多层网络与非线性表示
可以把这一层 f(x) 看作 x 的表示学习。十多年前，大家终于意识到这一点。原来 SVM 把这些变成黑盒：有输入，把它变成一个方程、一个函数，再优化，找到函数是什么。

还有一个重要结论：多层非线性神经网络可以拟合任意函数。这对表示学习非常重要。

课堂问答：样本选择与映射函数
同学提问
刚才讲到样本选择。比如只有15个点时效果可能还不太好，增加到100个点会好一些。如果有100个点可选，但只能选其中60个，这60个点应该怎么选？
唐杰回答
这是个经验问题。大模型出来以前，大家没那么关心它，早期通常多跑几组实验。现在模型越来越大，样本量与模型规模之间的关系就值得研究，这也是 Scaling Law 要讨论的问题，下一节课会讲到。
当时有一篇工作，好像是 Johns Hopkins 的一位教授和一位在 OpenAI 做物理学研究的人一起做的。它有经验主义，也结合了数学推导，能提供一些指导。大概是十几比一、二十比一这样的比例。
早期机器学习也讨论过类似问题。VC dimension 可以给出样本量的理论指导：如果希望把泛化误差控制在某个水平，可以计算大致需要多少样本。
同学追问
如果样本的 distribution 不一样呢？
唐杰回答
如果 distribution 很不一样，那确实是更难的问题，需要开始计算所选样本的 distribution。这里先假设样本是随机分布在这个空间里的。如果选出来的全是正例、没有负例，那模型就没法做。
同学追问
支持向量机中的 kernel function 对 φ 映射有一定要求。神经网络的每一层也可以看作一种映射，两种映射的要求一样吗？
唐杰回答
很不一样。原来 support vector machine 的映射，主要是为了计算方便，因为里面都是内积计算。每次映射以后，内积必须能够计算，否则会非常麻烦。
所以 SVM 的映射有很多条件，kernel function 也有专门的讨论。很多时候只计算 kernel function 的值，不需要真的把映射算出来，因此 kernel function 要满足一定条件。
同学提问
一般 kernel function 是从已经推导好的一组工具里选，不用自己再推一个新的 function，对吗？
唐杰回答
一般会有几种。很多 machine learning 工具里默认就有多项式、sigmoid 等三四种。也可以针对问题自己定义，比如 tree-based kernel：两棵树怎样算相似、怎样算最不相似，可以由人来定，也可以数叶子节点。
同学追问
那 φ 映射与神经网络每层的激活函数是一致的吗？比如某一层选了 sigmoid，映射也必须是 sigmoid 吗？
唐杰回答
这个映射跟前面的要求很不一样。神经网络每一层都有非线性。比较关键的结论是，每一层的非线性函数具体是什么，和最终能表征什么函数之间不必一一对应；只要具有非线性，多层组合后就可以表征更复杂的函数。
所以现在经常用 ReLU。它很简单，单独看表达能力不强，但每一层只要带一点非线性，若干层之后就可以表达复杂函数。
同学追问
它刚好既有线性的特征，又有非线性吗？
唐杰回答
它本质上还是非线性函数。它的线性部分是为了计算梯度。

CBOW 与 Skip-gram
假设一句话里有五个单词，前面两个、后面两个，中间是当前单词。每个词都有向量表示，把前后两个词组合起来，预测当前单词。预测过程和刚才看到的分类器一样，就是判断是不是当前词。
这里把上下文作为 feature，让模型自己学习一个合适的 feature representation，使它能够准确预测当前单词。
就是一个自学习过程，很简单。第二个办法叫 Skip-gram，用当前单词预测 Context，也就是前面两个、后面两个词。原理一样，只是反过来。

十二、分布式表示与 Word2Vec
层次 Softmax 与计算效率
算法很简单，但有些地方很 Tricky。预测 wₜ 时要记得词表非常大，和刚才经过选择的词表不同，这里要学习所有单词的表示，几百万很正常。要做 P(w) 的预测，最后归一化需要把它们加在一起，几百万项相加，计算量非常大。
怎么办？用 Hierarchical Softmax，把线性搜索变成二叉树搜索。以2为底，2的 k 次方，对应对数级搜索，把计算量大幅降下去。原理很简单：做一棵二叉树，把目标定义在一个位置。Word2Vec 相当于从2003年开始，花了10年，解决了 Distributed Representation 问题。
所有单词都有语义表示，不再是原来的0、1状态，变得可计算。原来自然语言不可计算；从这时起，每个词都有一个向量，就可计算了，大家一定要理解。
原来单词怎么计算？只能从计算机角度做搜索、匹配，不能叫语义计算，因为没有语义性。现在所有单词都有语义表示，接下来要做什么？
自然语言是一句话，比如“我喜欢清华”，词和词之间有关联。刚才每个词都学了表示，但在这句话里，“喜欢”前面肯定有主语。
Dependency 还没有处理，怎么办？简单的办法是 RNN。它不是今天才有的，早期有 HMM、马尔可夫链，还有 MEM、CRF 等关键词。
早期模型都是在 Model Dependency。比如时间轴上，昨天下雨，今天下不下雨，是时间依赖；泛化到文本，是一样的事情。
这些模型中有无向图，也有有向图。慢慢跳过它们，到了神经网络时代，可以把 RNN 想象成神经网络里的 Dependency Model。它 Model 什么？

十三、RNN、LSTM 与卷积模型
循环神经网络 RNN
神经网络中两者之间的关联。对一个样本 x，已经学到 Representation，可以叫 Embedding、表示，还要建模它和上一个样本的关系。中间至少学一个矩阵来表示关联。一个 Sequence 有10个单词，可以学矩阵描述相邻词之间的关系；从下面到上面、从 x 到 y，仍是神经网络，和刚才的 Forward Network 一样。
从输入 x 到输出 y，网络学习能够预测结果的表示；横向还要学习相邻词之间的依赖关系，因为前面的词也会影响当前输出。这里既有纵向的预测学习，也有横向的依赖建模。如果序列有10个词，就先计算第一个，再把状态传给第二个，然后传给第三个，依次计算。
问题在于，RNN 必须按序列一步步计算。早期模型小，影响有限；模型和序列变大后，不能充分并行的限制就很明显。
没法并行，就很慢。每个都这么算，不能利用几十万张 GPU 疯狂地跑，只能逐个等着计算。第二个问题是，模型是逐层的 Dependency。
比如一段很长的话有1000个单词，第一个和第1000个之间的关联可能很重要，但模型可能丢失了信息。还有梯度问题：根据 Chain Rule，一层层算，方程相乘。如果有1000层，算出来就很炸裂。
举个简单例子，每层通过链式法则相乘。如果每层都大于1，1.1的1000次方就爆炸；如果很小，0.5的1000次方就接近0，梯度没了。后来有人提出了解决办法。他做过很多非常优秀的工作，但脾气特别差。当时选图灵奖，大家选了 Hinton、Bengio、杨立昆，没有选他，他每次在公共场合都批评这三个人。我2020年请他做过报告，他说必须把他当图灵级的人来介绍。
他的水平确实很高，但脾气让人不太舒服。他是德国人，提出过很多范式，包括一些早期的重要前身，还提出过类似 GAN、对抗神经网络的模型。
他提出很多很厉害的东西，也很遗憾。LSTM 其实就是解决刚才的长距离 Dependency 问题：RNN 要么梯度爆炸，1.1的1000次方；要么消失，变成0。

LSTM 的门控机制
他设计了一些门，在某些地方切断传递。原来是1.1的很多次方，某个地方切断，就能保留需要的信息，不再一直往下传。
因此叫 Forget Gate、Input Gate、Output Gate，有不同的 Gate，还加了 State。每个 State 用上一个 State 计算，再由 Forget Gate 控制。
Input Gate 控制新的输入要不要加进来。每个节点通过 Forget Gate 控制上一个 State，通过 Input Gate 控制新输入。
Output Gate 控制要不要输出。多个 Gate 都可学习，由模型自己学。优美的地方在于，Dependency 要不要继续传、哪些信息继续传，可以自动学习。

但去掉一个东西，肯定要有原因。卷积取代前面的 RNN，是因为 RNN 有大家忍受不了的痛点；CNN、LSTM 都一样。现在要取代前面模型，Bug、痛点是什么？如果只从速度出发，其他方面没有变化，就不够。
现在可能的一个问题是知识压缩率：同样参数量，能不能学更多知识？就像刚才同学问的，小模型原来学得很好，如果压缩率更高，也许有另一种方法学得更好。后面有几个模型，像 Mamba 等，也在探讨问题：能不能用新架构？
让新架构学习、压缩效率更高，不用这么多参数，还能把知识学进去。假设成功，我觉得可能，是很好方向。但单纯提高速度，我感觉不够，没有理由推翻现有架构。除非找到更好的知识压缩率，提高两倍，甚至十倍。
计算机领域的人经常这样想：如果只是提高一倍，换硬件就行，比如把 GB300 换成 Rubin，什么都不用改。但提高10倍、跨一个数量级，就真正改变了，所以大家要研究这些。
我感觉研究上要颠覆范式，应该研究压缩率、压缩比，提高10倍或者几倍，可以直接研究。今天讲到这里，主要讲这些模型的功能和用法，下节课再延伸到 BERT 等内容。
