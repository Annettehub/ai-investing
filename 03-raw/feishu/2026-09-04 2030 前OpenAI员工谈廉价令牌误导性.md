持久护城河位于功能层之下
这位专家认为，持久护城河位于功能层之下，因为功能会被快速复制，并且很少能作为持久优势维持下去。GOOGL 脱颖而出，因为它通过专有硅芯片及其生态系统的分发渠道，拥有真正的结构性深度，这将需要数年时间才能复制。Anthropic 在特定工作流程中与开发者和企业用户建立了真正的粘性，这种基于习惯的护城河虽然不易察觉，但却意义重大。

OpenAI先发优势但忠诚度脆弱
OpenAI 通过 ChatGPT 的消费者分发渠道获得了强大的先发优势，不过这位专家指出，忠诚度很脆弱，因为切换只需打开另一个标签页即可。

中国实验室是真正的成本故事
这位专家将中国实验室视为真正的成本故事，并以 DeepSeek 为例，证明无需投入更多昂贵计算资源也能取得强劲成果。硬件限制迫使他们在效率上形成了真正的纪律性，这种效率看起来是结构性的，而非仅仅通过激进定价实现，不过这位专家提到，需要将廉价 API 价格与实际更低成本地产生智能区分开来。

不要过度解读公布的API定价
他警告不要过度解读公布的 API 定价，认为廉价令牌成本在工作负载复杂化后会隐藏许多问题。真正重要的是每完成一项任务的成本，这包括失败尝试、重试以及监督输出的人工时间。如果工程师必须全程"看护"模型，那么即使其原始成本便宜 20%，也会迅速丧失优势。这位专家仍不愿断言中国实验室在结构上更便宜，他承认其效率工作令人印象深刻，但指出市场尚未在大规模下充分验证这一说法。

基础设施：GOOGL和META处于最佳位置，电力是真正瓶颈
在基础设施方面，这位专家认为 GOOGL 和 META 处于最佳位置，因为它们多年来一直在建设数据中心、签订电力协议并开发自己的硅芯片，这赋予了它们相对于更依赖合作伙伴和外部容量的 OpenAI 和 Anthropic 的显著先发优势。电力被强调为真正的瓶颈约束，因为你无法在下季度就订购更多，而那些早有规划的公司相对于今天才起步的公司拥有真正优势，后者可能需要数年才能获得相同容量。

OpenAI和Anthropic的补偿方式
尽管如此，OpenAI 通过大型基础设施合作伙伴关系和资本进行了补偿，而 Anthropic 受益于来自 AMZN 和 GOOGL 的强大支持，这意味着两者并非从零开始。这位专家并不认为这会成为 GOOGL 的专属优势，但他指出，如果 AI 工作负载的形态发生意外转变，谁对技术栈的控制力更强，谁就会处于更好位置，而这位专家认为这种情况极有可能发生。
