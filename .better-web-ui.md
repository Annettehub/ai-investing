## Design Context

### Users
Annette and readers of her investment research knowledge base compare company theses, evidence, risks, and financial tracking data. The repository remains the source of truth.

### Brand Personality
Calm, precise, readable. This is a research workspace, not a marketing site.

### Aesthetic Direction
Use the supplied Laopu reference: near-white surfaces, a pale mint navigation rail, dark readable text, green/red full-text bull/bear comparisons, and restrained amber warnings. Keep sections unframed and use cards for repeated data items. Use an 8px corner radius.

### Implementation Defaults
Preserve the existing Astro 7 / Starlight site and deployment. Build the entity preview as a scoped Astro layout. Use the installed Starlight icon library, semantic tables, and a real Markdown AST parser. Existing stack takes precedence over framework fallbacks. No backend, credential changes, or new publishing pipeline.

### Design Principles
- Preserve original prose, table cells, notes, and source qualifiers; never generate summaries during rendering.
- Select modules by section meaning, not fixed chapter numbers or company-specific financial values.
- Derive charts and metric highlights from source cells; retain periods, units, estimates, and verification flags.
- Keep desktop comparisons aligned; stack on narrow screens without clipping text.
- Preview locally and verify against source before any separately authorized publication.
